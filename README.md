# 慢行 · SenseWalk

帮助人找回感知与耐心的 Android 应用：先选场景（雨林 / 森林 / 沙漠 / 城市等），再虚走或实走；**走满距离才能通关**，感官与景色层随路程渐渐解锁（从黑幕层层展开）。不可跳过、不可加速。

## 产品计划（推荐先看）

**[打开可视化计划页 →](./docs/plan.html)**（单文件 HTML，可双击离线打开，支持深/浅色）

完整 Markdown 方案见 [DEVELOPMENT.md](./DEVELOPMENT.md)（**v0.5**：景色层层展开 + 多场景声音身份 + 距离门禁 + 双模式）。

## 核心规则

- **先选场景**：各景有独立声音与景色身份；解锁机制相同（距离门禁）
- **景色层层展开**：关卡内从黑幕起，按路程逐步丰富该场景风景（树木、沙丘、街灯等）
- **双模式**：手机控角色（虚走）或户外实走（计步 / 可选 GPS）
- **距离门禁**：进度 = 有效距离；未满要求米数不能通关；长按 = 放弃
- 感官与视觉层随 **`atMeters`** 展开；耳目同程、不可加速揭示
