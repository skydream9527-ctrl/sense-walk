## 1. H-SW-018-R1 提示截图亲自实看与像素量化复核（Requirement 1）

1. **直接目视与像素级核查**：
   - 亲自查看 [H2-hint-appear.png](../../evidence/H-SW-018-R1/screens/H2-hint-appear.png)（SHA256 `96faa8fa...`）、[H2-hint-gone.png](../../evidence/H-SW-018-R1/screens/H2-hint-gone.png)（SHA256 `8a3762eb...`）与 [F3-completed.png](../../evidence/H-SW-018-R1/screens/F3-completed.png)（SHA256 `2a5550b3...`），并输出量化审计 [h2-pixel-audit.json](../../evidence/SW-024/h2-pixel-audit.json) 与追加勘误 [R-SW-018-R1-correction.md](../../reviews/R-SW-018-R1-correction.md)。
   - **中央提示文字不可见**：在中央卡片区域（`x ∈ [100, 980], y ∈ [950, 1450]`），含说明卡的 `02-virtual-session.png` 有 `14,056` 个高亮像素（`max RGB = [232, 228, 217]`），而 `H2-hint-appear.png` 高亮像素为 **`0`**（`max RGB = [33, 46, 40]`，纯森林背景），未拍到「慢一点，站稳再跳。」文字。
   - **旅人姿态实为 `Gait.HOP` 腾空帧而非 `Gait.TENSE` 微蹲**：平地静止/行走（`02-virtual-session.png`、`03-walking.png`）旅人 `#7A857C` 纵向为 `y = 1981..2076`（`groundY = 2076`）；若为 `Gait.TENSE`（`tenseDuck = +6px`），纵向应为 `y = 1987..2076`。实测 `H2-hint-appear.png`（`y = 1957..2050`）与 `H2-hint-gone.png`（`y = 1955..2049`）脚底均离地抬高 `26px`（`2076 - 26 = 2050`），证明两张图均处于跳跃态 **`Gait.HOP`**。前图带 `-10°` 后仰与攀爬手臂是因为 `sPos ∈ [237, 240)` 仍在 `140..240m` 的 `slope_up` 段；后图已进入 `240..270m` 的 `gap_hop` 段。
   - **时序根因**：`sPos = 237.0m` 触发 `1.2s` 站稳与 `3.0s` 提示卡片；作者脚本先执行阻塞式 `uiautomator dump`（60fps `withFrameNanos` 下等待空闲超时约 `1.5–2.5s`），待 XML 返回宿主机后再执行 `screencap` 时已超过 `t = 3.0s`，错过了 `1.2s` 微蹲与 `3.0s` 提示窗口。
   - **保留项与边界**：`F3-completed.png`（「走到了 / 走完 800 m」）真实可见，结论单独保留；历史 `H-SW-018-R1` / `R-SW-018-R1` 不覆盖，`SW-018` 整体 `accepted` 不撤销；同步提示画面与时间线保持 `Pending` 并已提供 400ms 非阻塞连续抓拍复核步骤。
