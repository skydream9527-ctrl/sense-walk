### 2. 真实生图 (8/8 尝试, 逐次入账)

生图服务返回 **无 alpha** 的 RGB, 故按任务文件用 **可分离底 + 逐像素验图**: 让模型在纯洋红 `#FF00FF` 平涂底上画孤立单层, 再用反解混合方程 `obs = a·F + (1−a)·bg` 求出真 alpha 与前景真色 (不是简单按色距取 alpha, 否则软光斑会把底色混进结果)。

| seq | 层 | 结局 | 说明 |
| --- | --- | --- | --- |
| 1 | probe_reference | **failed** | 纯文生图, 模型理解成整幅森林场景, 底色只出现在天空缺口, 非可分离孤立层 → 候选被拒 |
| 2 | trunks_canopy (a2) | **failed** | 纯文生图同上, 四周仍是暗绿场景 → 候选被拒 |

### 3. 后处理链 (每步可追溯, 记录在 manifest 每层 `process`)

`source/*.png` (1536×2752) → 反解混合方程求真 alpha → 等比 LANCZOS 缩放并中心裁切到 1080×1920 → alpha 密度标定到批准 design 实测统计 → 色域收敛到批准色板统计 → alpha 量化 64 级 + 3×3 中值去噪 → PNG(RGBA) + WebP.

- **尺寸诚实**: 来源 1536×2752, 经等比缩放 + 中心裁切得 1080×1920, **非原生 1080**, manifest `source_resolution` 与 `process` 均如实记录.
- **色域收敛只取统计量**: 从 SW-012 批准 export 取色相/饱和/明度**分布统计**, 把生图层收敛到批准区间; **未搬运 design 的任何像素** (符合 visual-assets "不把设计 exports 冒充生产候选").
- **alpha 密度对齐**: 每层 alpha 最大值与批准 export 实测一致 (mist 144 / trunks_canopy 255 / vines_light 255 / distant_glow 57 / glade 237), 避免破坏运行时 phase opacity 衰减语义.

## 风险与待验证

- **875m 合成仍略亮于批准 design 阶段稿** (实测亮度 51.1 vs 批准稿 33.8). 色相/饱和已收敛到同一冷湿绿区间, 但整体明度偏高约 1.5×. 已在 manifest `limitations` 记明, 是否需要再压一档请审核判定.
- **生图模型倾向平滑光斑**: `distant_glow` 的"斑驳漏光"与 `glade` 的"湿径反光"在成片里比批准 design 更柔更连续, 可能弱于设计要求的斑驳感, 请重点目检这两层.
- **`vines_light` 点状光斑**由模型生成, 是否存在等距重复感需目检 (设计明确禁止"串珠式等距重复斑点").
- **alpha 反解精度**: 极细发丝/藤尖边缘有 1–2px 精度损失 (反解软边所致), 影响面小但请目检局部放大图.
- **来源分辨率非原生 1080**: 1536×2752 等比缩放 + 中心裁切而来, 已如实记录, 不冒称原生.
- **8 次预算已用尽**: 若需按本设计重做, 需另行明确新增预算; **不得换 revision 重置账本** (账本在 `design/assets/rainforest/candidates/SW-006/api_ledger.json`, 跨 revision).
- **tileable=false**: 未提供也未宣称无缝平铺; 运行时仅支持右侧溢出宽度内有限横移.
