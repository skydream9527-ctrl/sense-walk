## 文件结构

- `source/sw011_model.py`：统一图元/色板/相位模型；`source/sw011_render.py`：PIL 导出+合成+裁切+分层标注；`source/sw011_supplement.py`：本轮放大与运行时裁切复核；`source/svg/*.svg`：5 个图层矢量源。SVG 与 PIL 共享同一模型，保证矢量源与导出一致。

- `previews/`：统一风格参考、构图引导、分层标注、六阶段合成（0/80/240/400/600/760/785m）、三比例裁切（20:9/9:16/9:19.5）、分层检查、`zoom/`、`runtime_crop/`。
- `prompts.md`：每层独立、逐层渐进、负向、规格与 MiniMax 制作注意事项。

## 关键设计决策

- 完全保留现有森林四层色板、相位与 parallax，不新增/删除/改名图层，不改 `forest.json` 与 App 源码；旅人锚点（x=.34, y=.865）与下方 45% 触控区在各阶段不被遮挡。
- 结构性解决历史 `light_shows`/`clearing` 棋盘格/矩形硬底：两 overlay 全部改为纯解析软渐变（椭圆/圆形径向渐变，源移出画面），不使用任何平铺位图，四边连续平滑衰减。
- 树干加入竖向体积渐变（两端暗、中上亮）并保留一根前景纯剪影树干增强层次；林间竖光压到 α ≤ 0.11 仅作空气感，避免竖条/硬光束。
- 裁切严格对齐 App 运行时：恒可见带推导为 x∈[216,864]（1080 画布），关键内容（旅人锚点、树干/树冠/光斑）均落在该带内，右侧溢出供横向视差。
- 纯本地 Python（PIL + numpy）生成，零外部付费 API。

## 自检与证据（量化）

- 边缘/棋盘（`previews/zoom/` + `previews/layer_checks/edge_check.json`）：两 overlay 四边均无实色亮边/白边，外缘不亮于内邻；`light_shows` 边缘最大 α=15、`clearing` 最大 α=21，且均为连续软渐变，无矩形底/同心环。结论 pass。
- 运行时裁切（`previews/runtime_crop/runtime-crop-check.json`）：恒可见带 x∈[216,864]，旅人锚点 x=367 在静止与最大视差两极端均恒可见；两 overlay 在视口四缘无实色边/白边。结论 pass。
- 相位/透明度：六阶段实渲与 `forest.json` 的 80m/.6/20、240m/.7/25、400m/.8/25、600m/.65/30、760m/.9/25 对齐，parallax 0.3/0.3/0.6 一致。
- 可复现性：`design-manifest.json` 53 个文件 SHA256/字节独立复算 0 处不符；SVG 与 PIL 共享模型。
- 说明：本包是**设计稿**，不是素材候选，也不是 Android 接入或真机证据；未运行 Android 构建/真机/真人计步（设计阶段不适用）。
