## R1 缺口补齐（P-20261015-02 指出：提示与步态无 UI 消费者）

1. **站稳提示 UI**：`SessionViewModel.stabilizeHint` 一次性事件
   （onFrame 消费 `consumeStabilizeHint`）→ SessionScreen 提示卡片
   「慢一点，站稳再跳。」——3 秒自动消失，无交互、非 QTE、不阻塞行走。
2. **步态表现**：ForestShell 接收 `snapshot.gait`——HOP 腾空（腿收并、
   footY 离地；reduceMotion 压小幅度但不抹除语义必要动作）、TENSE 微蹲
   外撑；walk/climb 姿态不变；UI 只消费状态，动画不驱动 s_pos/meters/s_best。

## 死区边界（规划要求 d=.01/.08 实际 Kotlin 用例）

`TerrainMotor.INPUT_DEADZONE = 0.08f`（与 comfort_v1 曲线死区一致）：
死区内曲线速度为 0，等同无输入——不触发/中止 HOP、站稳中按松手处理。
+5 单测：d=0.01 / d=0.079 不跳；d=0.08 正常进入越坎流程；STABILIZE/HOP
中死区输入中止。修复了"死区输入可自动跳坎刷距"的边界缺陷。

## 恢复局提示语义（R-SW-005-R1 P-02：同局仅提示一次）

恢复沿用原 sessionId（SW-004 冻结语义）。**P-02 裁定**：同局恢复不得
再次弹出提示——`stabilizeHintShown` 现随快照持久化（SessionSnapshot 新增
**可选字段**，旧档缺省 false 兼容、主动结束随清快照一并消失；快照版本

`TerrainMotor.restoreHintShown` 还原。+2 单测：同局恢复不重复、
未发过提示的局恢复后首次站稳正常提示；JSON 往返含该字段。
