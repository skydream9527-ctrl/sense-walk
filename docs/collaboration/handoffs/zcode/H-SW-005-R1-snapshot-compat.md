# SW-005 快照兼容决策 · 无新增持久字段

对已冻结 [session-snapshot 契约](../../contracts/session-snapshot.md) 的地形扩展兼容决策
（SW-005 任务要求：新增持久 terrain 字段前先交具体兼容决策）。

## 决策

**不新增任何持久化字段，快照版本保持 1。**

理由：TerrainMotor 的全部状态（FREE/APPROACH/STABILIZE/HOP、站稳计时、
首局提示已发标记）都是**瞬态表现态**，不携带跨会话语义：

- **站稳/跳跃中被动中断**：恢复后角色位于 s_pos（快照冻结值）。若 s_pos 在
  坎内，TerrainMotor 的 FREE 分支对"有输入且在坎上"直接进入 HOP 跳过——
  恢复不卡死（单测 `快照恢复落入坎内 - 不卡死能通过` 锁定）；若在坎前接近
  区，重新走接近/站稳判定（与首次到达行为一致，不恢复"站了一半"的中间态）。
  这符合契约"恢复按当前米数重建静态感官"的同款哲学：重建而非续播。
- **首局站稳提示**：中断恢复视为新一"局"提示可再发一次——提示语义是
  "本局第一次站稳"，恢复局是新局，允许再提示不构成重播违规（一次性
  **相位提示**不重播的规则针对 PhaseScheduler 的 phases，与此独立）。
- **不把旧档静默当新结构**：无字段读取歧义——旧快照（SW-004 版）与
  新快照字节级同构，SW-004 的 25 项快照回归全部原样通过（本轮 296 项
  含其全部）。

若未来需要持久化"站稳中"的精确中间态（当前决策不需要），须升
snapshotVersion 并在 validator 中对旧版本给出 Incompatible 可解释结果，
不得默认旧档已包含新字段。
