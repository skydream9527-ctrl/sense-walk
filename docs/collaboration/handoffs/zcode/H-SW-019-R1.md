## 交付内容（对照任务书四项）

1. **场景目录单次装载缓存**：`SceneCatalogCache`（纯 Kotlin）+ `SceneCatalog`（Android 单例）。single-flight（LAZY Deferred + inFlight 注册表）、失败不缓存可重试、`reload()` 供“重试”按钮强制刷新。接入点：SessionViewModel init 预热、SenseWalkViewModel loadScenes、WalkForegroundService setupSession。
2. **森林图层位图异步解码与缓存**：`LayerImageCache<V>`（LRU 字节预算 32 MiB、accessOrder、超预算单项返回不缓存）+ `ForestLayerImages`（inJustDecodeBounds 两段采样，`layerSampleSize` 取满足目标高度的最大 2 的幂、不放大小图）+ `ForestShell` 的 `LaunchedEffect` 逐层装载；解码失败走程序降级绘制，不缓存失败。
3. **高频状态读取下沉**：会话各屏改为 `State<Snapshot?>` 直传，快照在 Canvas draw lambda 内读取（只失效 draw，不触发重组）；`session`/整数米/`moving` 用 `derivedStateOf`；米数仅在显示时订阅（`MetersReadout`）。
4. **未做无度量池化**：`drainPhaseEvents` 已是 swap-not-clear；Path/Brush 池化按任务书要求未实施（无度量不优化）。

附带：`produceState` 缺陷规避（其内部 state 不随 key 重置，跨场景会残留旧值）→ 改用 `remember(keys){mutableStateOf}` + `LaunchedEffect(keys)`。

## 关键质量事件：真实协程竞态（CI 抓到）

run 39433774837 在 2f46993 上 1/328 失败，本地串行 8 次不复现；10 万轮压力复现器第 440 轮捕获根因：**Deferred 完成先 CAS 终态、后执行 invokeOnCompletion 清理，await() 快路径可在清理前返回**——窗口期内新请求 join 到已失败的 inFlight 项，重试语义失效。修复：加入前检查 `isActive`（两个缓存同构修复，a666b76）。修复后 10 万轮干净，回归锁进套件。
