## 字段模型（冻结建议，交 Antigravity 形成契约决策）

按任务要求先冻结具体字段/版本/boot 语义再实施；实现即以下模型（`domain/session/SessionSnapshot.kt`）：

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| snapshotVersion | Int = 1 | 快照格式版本（与场景 schemaVersion=2 独立） |
| sessionId | String | 会话标识（UUID；恢复后沿用原 id） |
| mode | String | "virtual" / "real"（与 NavRoutes.Mode 一致） |
| sceneId / sceneSchemaVersion | String / Int | 场景与 schema 校验（不符=不兼容） |
| state | String | 仅 WALKING/PAUSED 可为恢复候选 |
| savedAtWallMs | Long | wall time，仅用于 30min 时限 |
| bootCount | Int | Settings.Global.BOOT_COUNT；跨 boot 标记（不拒绝） |
| meters/sPos/sBest | Float | 进度（validator 拒绝 NaN/负/超终点/sBest<sPos） |
| firedPhaseIds | List<String> | 已触发相位（恢复不重播） |
| elapsedActiveMs | Long | 累计活跃时长 |
| lastCounterReading / lastCounterEventMs | Long? | 实走诊断值（恢复不据此补距） |

序列化：手动 JSON（项目未启用 serialization 编译插件），未知字段前向兼容、
损坏输入返回 null。样例：
```json

```
（实测捕获自模拟器 DataStore，见 emulator-recovery.txt）

## 语义要点（契约 → 实现映射）

- 保存时机：5s ticker + 越相位 + 状态转换（暂停/恢复/进后台）；不依赖 onDestroy。
- 清除：主动放弃/通关（含通知栏停止=放弃路径）。
- 恢复窗口：被动中断后 30 分钟内由用户在 MODE 页显式选择；过期/损坏/不兼容
  各有可解释结果（对话框不出现，残留清除，直接新会话）。
- 虚走恢复：READY 等新输入（无输入帧不前进）；实走恢复：counter 重新建基线、
  中断/跨 boot 缺口不补算（engine 初始 rebasePending）。
- Activity 重建：HOME 往返同会话（VM 存活）；实走活服务经 hasActiveSession
  标志直进会话重绑，不起第二套恢复引擎。
- 感官恢复：按当前米数静态重建（loop 满淡入落目标增益），一次性提示/旧脚步
  不重播；音频焦点门控不变（setAudioAllowed 机制未动）。
