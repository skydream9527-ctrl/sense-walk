# D-003 设计引用的历史与当前语义

日期：2026-10-13（America/Los_Angeles）。状态：adopted，D-002实现边界补充。

在新增Trae校验的多轮推演中发现：若所有历史素材handoff都被要求引用“最新”设计，设计R2获批后，原本合法的R1素材记录将永久失败；不可变交接历史又不能覆盖。改为分别检查历史与当前语义。

每条引用都必须绑定其当时的真实design handoff/head/spec哈希和独立approved记录。当前最新新交付，以及registry仍登记accepted的交付，还必须匹配当前批准设计与任务前置。已被新revision替代的历史交付、被协调者明确登记rework/blocked的旧交付，仅保留当时引用校验，不获得新入包授权。协调者批准设计变更时须同步退回受影响素材及重新安排接入依赖。

本次只修复协作校验边界，schema_version保持1；没有实际设计/素材交付或生产代码修改。历史证据与D-001/D-002原文保留。
