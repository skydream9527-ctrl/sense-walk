SW-004 模拟器行为实测（T07A 会话快照与中断恢复）
设备：emulator-5554（api36_test）；APK：本分支 debug 构建（含 SW-004 全部改动）。
实走计距由 DebugStepReceiver 冒烟注入驱动（不构成真实计步验证）；虚走用真实摇杆手势。
杀进程用 `am crash`（系统级被动中断，非优雅关闭）。

[1] 实走被动中断恢复（WALKING 快照）
  注入走到 295m（等 ≥5s 让周期 ticker 保存）→ am crash → 服务无残留（ServiceRecord=0，
  START_STICKY 空重启正常退出）→ 重启 app → 森林/实走/开始 → 恢复对话框出现：
  "上次在实走森林走到约 295 m 时中断了" → 点「继续」→ 会话恢复：
  注入 counter 基线(1000)→+2 步 → 米数 296 m（恢复后首事件只建基线、
  中断期缺口不补、新步正常计距）。PASS

[2] 主动结束清除快照（通知停止=放弃）
  恢复会话(296m) → 通知栏「停止」→ 结果页"这次走了 296 m" →
  返回模式页：无恢复对话框（快照已清）。PASS

[3] 虚走被动中断恢复（WALKING 快照）
  虚走拖摇杆走到 ~10m 保持按住 → am crash → DataStore 快照验证：
  state=WALKING, meters=2.74, firedPhaseIds=["void"]（周期 5s 保存生效）→
  重启 → 虚走/开始 → 恢复对话框"上次在虚走森林走到约 2 m"→ 点「继续」→
  拖摇杆前进 → 11 m（恢复后正常计距、能继续走）。PASS

[4] HOME 往返同会话（Activity 重建不另起恢复引擎）
  虚走 106m → HOME → 重新打开 → 同一会话 106m 保留（VM 存活；未触发恢复路径）。PASS

[5] 被动中断与恢复语义边界
  - 松手后（READY 态）crash：快照保存 state=READY，恢复对话框不出现
    （READY 非可恢复候选——未开始走没有恢复价值，与 validator 设计一致）。
  - 结果页放弃后重进：无恢复对话框。PASS
