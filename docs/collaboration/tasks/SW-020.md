# SW-020 · 安全操作区、步长设置与一次性触感

owner=zcode，kind=code；初始queued，SW019 accepted后由Antigravity启用。只补已有规格缺口，不改距离、速度曲线、terrain判定或GPS能力。先读[合并计划](../plans/2026-10-20/README.md)。

## 实现范围

- 会话双模式/结果页面保护控件与操作手势的systemBars/displayCutout安全区，去掉用于代替insets的固定64dp/48dp假设。背景继续全屏，操作区按安全内容区划分上55%/下45%；不重复消费Scaffold已处理的insets，键盘不遮挡步长输入/确认。
- `UserSettings`/DataStore新增strideMeters，缺省0.70m、范围0.45–0.95m。手动输入与身高估算（身高m×0.415）均先显示米制结果，确认才保存；cm与m明确换算，拒绝NaN/Infinity/空值/非法范围，不静默存错值。
- 服务开始会话从已确认设置取步长并传入RealWalkController/Engine。当前会话冻结步长；设置变更只影响下一局，不能追算已走米数。被动恢复同一局保存/还原其步长；快照新可选字段必须兼容旧档（旧档默认0.70）且旧快照不因缺字段全失效。输入值/单位/恢复/1.4m/s上限要有针对性测试。
- 摇杆首次进入舒适区和紧张区分别一次极轻反馈，每局各一次。服从vibrationEnabled和rhythmHint；关闭时不反馈、不补播历史进入事件。标记属于sessionId，不属于某次Composable挂载，暂停/旋转/同局恢复不重发，真正新局才重置。旧快照字段兼容。无振动器安全降级，按住前进不在每帧重复触发。
- 修正设置页“引擎下一版接入”等过期注释/文案；现有全局振动开关继续控制真实backend。保留可访问的按住前进替代，不默认强开或增加自动行走。
