## 实现范围

1. `ForestShell`图层读取/解码移出组合期同步路径；按实际目标尺寸选择采样，不为大屏无意义预放大。缓存有明确上界，键含场景/素材身份与必要尺寸；异步取消/旧请求返回/解码失败要安全，失败回退程序层且仍受原opacity门控。
2. 消除`RealWalkVisualCache.runBlocking`等待。复用服务已加载SceneConfig或实现轻量进程级SceneRepository缓存，保留加载错误/显式重试；并发首次请求只加载一次，失败不永久缓存为成功。不得为此新增Hilt/多模块。现有preferencesDataStore无需重复造容器。
3. 将walk/sensory等高频读取下沉到真正绘制消费处；顶端文字、弹框与操作容器不再因绘制位移被无谓失效。整数米数仅显示时消费。FrameNanos和音频/地形驱动仍唯一，不降低进度采样或用时间替换距离。
4. 测量确认后才复用Path/Brush或调整事件分配。不要一边把mutable列表交给消费者，一边clear同一列表；相位淡入区间仍逐需计算，音频/提示事件不丢失。
