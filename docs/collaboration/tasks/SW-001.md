## 必须完成

1. **F-001 同时间戳刷距**：当前 intervalMs<=0 分支给 strideMeters。基线(0,1000)，之后(100,1000)/(200,1000)会各加0.7m，违反1.4×0s=0。零/负有效间隔不得产生距离，不得通过无限同刻事件刷进度。明确重复/乱序读数的基线策略，确保后续正常事件既不补暂停缺口也不重复累计。替换旧“同刻计一步”的错误断言，增加连续100批同刻读数、下降且乱序、正常重启、批量跨相位用例。步长非有限值不得污染 meters。
2. **F-002 空服务重启**：START_STICKY 的 null Intent 当前仍进入前台，但无sceneId无法装配。T07恢复前采用明确安全策略：没有有效活会话/恢复候选时不留下空通知/服务。也测试 setup中停止、重复start和销毁后的迟到协程，不能创建第二套控制器/音频/监听器。
3. **F-003 注册失败**：StepSensorSource 忽略 registerListener 的实际返回值，服务也忽略 start()。使用真实结果区分硬件存在/注册成功；失败提供可解释回退并清理部分注册、服务、音频与通知。测试 counter失败/detector成功、权限变化、重复stop。
4. 核查 sensor timestamp 与应用单调时钟在锁屏/休眠/重启下的语义，跨不同基准不能相减。以官方文档核对所需服务类型与 health/mediaPlayback 权限；当前仅health，不机械追加类型，记录实际功能与依据。
