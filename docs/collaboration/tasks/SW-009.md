# SW-009 · T09 真机内测与发布候选验收

状态/依赖以 [registry](../registry.json) 为准。负责人：antigravity；类型：coordination。

汇总持续真机验证并组织最终候选。Android10–13、14–15及目标品牌省电策略；真实counter/锁屏15min/耳机来电/通知停止/杀进程/重启/权限拒绝/完成放弃；记录实际机型和版本。

5–8位真实用户，标准距离首次理解、拇指负担、静默理解、主观紧绷前后与退出原因。不可编造参与者或以自动脚本替代人。缺设备/人仍交可安装候选与Pending清单，不宣布最终MVP。

确保release无调试注入入口、素材来源与署名可查看、包体预算、无严重未关闭问题。出acceptance-report，每项Passed/Failed/Pending、证据、问题级别、修复复测与剩余决策。测试Release有准确SHA/APK/source/hash。无正式签名密钥或应用商店发布。

执行通用入口要求：独立checkout/任务分支，按handoff协议记录真实检查与未完成项；未获独立审核不得自批准。
