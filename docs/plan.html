1. 产品愿景

用慢感官行走练习耐心与放松。选景定耳目，走路开锁层，满距才通关。急推摇杆、冲地形都帮不了你更快清关。

耐心 · 减压产品目的：培养耐心、缓解压力，而非刷关冲刺。
先选场景大卡片进入；各景声音与景色身份不同。
舒适节奏摇杆甜点区最快；拉满变钝，教你放松。
地形联动路有起伏；爬坡、跳跃贴合场景，宽松不焦虑。
黑幕起笔会话从虚空开始，风景按距长出。
距离即通关未满要求米数不能完成；不可跳过/加速。

2. 开局流程

进入 App 后三步：选场景 → 选模式 → 开始。景色层层展开发生在关卡会话内，选景页不大片剧透完整风景。

01
场景选择 大卡片：雨林 / 森林 / 沙漠 / 城市（及可选夜径）。展示情绪词与要求距离；极弱主题色即可。
02
模式选择 手机控角色（虚走）或户外实走。按需申请计步 / 位置权限。
03
开始关卡 进入会话：黑幕起笔 → 音视振按距解锁 → 满距通关。

3. 双模式行走

手机控角色

Virtual Walk

屏幕虚拟摇杆；舒适甜点曲线；硬顶 ≤ 1.4 m/s。

  • 拉满 ≠ 最快——中段偏转才是舒适步速
  • 无冲刺、无加速条、无倍速
  • 角色走在随距展开的景色与起伏路径上
  • 适合室内 / 先熟悉关卡节奏

户外实走

Real Walk

counter × 步长，速度帽 1.4 m/s；GPS 校准放 P2。无摇杆。

  • STEP_COUNTER 主路径
  • 「舒适节奏」→ 可选过快平静提示（不惩罚通关）
  • 景色规则相同（可少层，仍从黑幕起）
  • 地形仅作氛围，不要求户外做跳跃操作
  • 计步器不能可靠辨别原地踏步 / 倒走
  • 实走、后台音频与中断恢复一并交付

4. 舒适节奏摇杆 · comfort_v1

虚走核心手感：摇杆→速度非单调。中段是甜点；推满反而变慢——用机制教耐心与放松。

屏幕上有一个虚拟摇杆，摇杆拉到最大并不是角色走得最快的时候；玩家需要学会放松，找到一个舒适的节奏。 — 用户需求（忠实并入本版）

摇杆偏转 → 速度（示意）

0静立
~0.3缓行
~0.7 m/s
~0.55甜点
1.18 m/s
~0.85紧张
~0.95 m/s
1.0拉满
~0.65 m/s

峰值落在偏转 ≈ 0.45–0.65；任意点硬顶 ≤ 1.4 m/s。曲线连续插值，禁止阶跃。不常驻「最佳角度」数值准星，避免变成竞技瞄准。

非单调v(满) < v(甜点)；急推对自己不利。
硬顶不变瞬时 ≤ ~1.4 m/s 步行感；无倍速作弊。
教学文案「推满不会更快。松一点，找舒服的节奏。」
门禁仍在再放松也不能快于距离门禁下界。

虚走 vs 实走

虚走 · 有摇杆

  • 甜点区 = 舒适步行峰值
  • 拉满 = 紧绷变慢
  • 可选短暂「节奏正好」提示（可关）

实走 · 无摇杆

  • 真实步伐累计距离
  • 过快步频 → 可选极轻提示「放慢一点」
  • 不取消通关资格；无 GPS 时不承诺识别车载

5. 地形动作 · 先坡后跳

背景路径不是平的。角色动作贴合地形（爬坡、跳跃等）；难度服务正念慢走，不做高压平台闯关。

角色移动的节奏要和地形挂钩：风景里的路不是平的；支持跳跃、爬坡等与地形相关的动作。 — 用户需求（忠实并入本版）
缓坡 / 沙丘上坡攀爬动画 + 自然降速；与「别急」同向。
浅沟 / 路缘轻跳 / 抬脚越过；时间窗宽松。
不平地面步态微调；湿根、落叶、砖缝各景不同。
失败很温柔无扣命；短暂停步后重试；不轰炸失败弹窗。

有效距离会计

有效进度 = 虚走沿路径向前的有效位移（历史最远位置；重试不刷米）
计入沿路径前进；成功过坡/跳后的前进段。
虚走不计入原地动画、来回刷同一坎、倒走、偏离路径。
减压优先地形鼓励慢看路，不诱发挫败焦虑。
实走简化户外不要求跳跃操作；起伏可作氛围剪影。

分场景气质

场景地形元素典型动作
雨林湿根、缓坡、浅沟攀湿坡、轻跃小沟
森林土坎、落叶坡上坡、越矮坎
沙漠沙丘起伏、软沙费力上坡（自然降速）
城市路缘、缓坡道上台阶感轻跳

6. 距离门禁（不变）

通关 ⟺ 有效距离 ≥ requiredDistanceMeters
不可跳过无跳关；视觉层也不可跳过揭示。
不可加速虚走速度帽 + 甜点曲线；景色不可快进。
不可提前通关未满距结束 = 放弃。
时间≠进度完成态只认有效米数。

7. 景色层层展开 · 继承 v0.5

视觉与音效 / 振动平行解锁：同一距离时间轴，从黑幕到场景风景，一步步丰富。

景色方面也应该层层展开：从一片黑幕开始，然后逐渐有适应场景的风景，比如森林场景的树木、沙漠环境的沙丘等等，一步步逐渐丰富。 — 用户需求（忠实保留）

10. 诚实原则

策略做法
速度帽虚走 / 实走限制最大折合速度（≤ ~1.4 m/s）
摇杆诚实拉满变慢是设计，不是隐藏惩罚梗；不包装「加急高级玩法」
实走能力边界计步估距不证明方向；GPS 后续可辅助识别车载，不承诺完全防刷
文案「还需要再走约 N 米」——不说作弊；通关不打操作分
隐私最小权限；位置可选；数据默认本地
视觉诚实不走路则景色不长；满距才是通关
地形诚实有效前进才计距；重试不刷米

  • 分模式校准用时；大字号 / TalkBack；多系统真机与省电验证

验收：最终 MVP 条目全部有证据；严重问题关闭后出候选包。

P2：GPS 步长校准、夜径精修、本地累计米数、短程路线、Wear。完整任务见 DEVELOPMENT §13。

12. 验收与开放决策

MVP 验收

  1. 选景 → 选模式 → 开始 ≤ 4 次点击。
  2. 至少雨林 / 森林 / 沙漠 / 城市 四个场景可选，音+视+地形气质独立。
  3. 未满距不可通关；无加速 / 跳过（含视觉揭示）。
  4. 虚走：甜点曲线成立（拉满慢于甜点）；硬顶 ≤ 1.4 m/s；实走可步数通一关。
  5. 各场景层解锁逻辑一致（atMeters）；音色与景色元素不同。
  6. 会话起于黑幕；景色按路程层层丰富，与音/振同一时间轴。
  7. 地形：至少平地 + 坡 + 一种轻跳/越坎；有效前进不刷距。
  8. 文案体现耐心与减压定位；主动放弃不续，被动中断才可恢复。
  9. 停走脚步音停止，视觉 opacity 不再推进。
  10. 实走锁屏 15 分钟计步 / 声音 / 相位正常；中断恢复不重复通关。
  11. 用时分模式校准；S1–S9 单测通过，真机验收有记录。

开放决策

#议题建议
1MVP 是否露出夜径配置保留；内容精修放 P2
2模式：独立页 vs 抽屉独立一步更清晰
3虚走操作摇杆（含甜点曲线）；按住可作降级
4实走强制 GPS否
5放弃后续走首版不续，重开清零
6视觉与音频是否强制同表同 atMeters 轴即可
7实走景色层数可少层，必须仍从黑幕起
8甜点「正好」提示默认短暂一次；设置可关
9跳跃：自动 vs 轻点自动跳 + 站稳规则；内测验证负担

13. 完善与改进 · 优先做什么

P0 = 下一闭环必需；P1 = 完整 MVP 必需；P2 = 有证据后再做。体验建议仍待用户验证，不直接改掉距离门禁。

P0 · 交付范围

先完整走一段森林

一景跑通距离、摇杆、解锁与结果，再复制内容。用测试和真机证据记录完成，避免文档进度代替实现进度。

P0 · 首次体验

让黑幕等待可理解

森林第一相位在 80 m，静默可能超过一分钟。补短暂说明、摇杆输入反馈和按需米数；声景仍只按距离解锁。

P0 · 操作负担

验证拇指是否累

持续控制约 13 分钟可能与放松冲突。M1 就接按住前进和手动暂停；用完整体验验证疲劳，不靠自动行走替代输入。

P1 · 地形体验

减少挫败感

先缓坡，再一个自动越坎。记录站稳等待和紧张感，给温和可关闭提示，决定是否值得增加更多事件。

P1 · 可靠性

把恢复和计步算清楚

保存历史最远位置、计步基线与时间戳；处理批量、重启、暂停、缺 detector。只有 counter 也可走，门禁不使用显示插值。

P1 · 效果验证

完成率之外看放松感

内测自愿做前后紧绷程度自评、退出原因与控制负担访谈。目前没有用户数据，先验证机制，再扩内容。

工程与文档还要补齐

  • 可观察的场景加载错误、配置 / 素材校验、可复现构建与 CI。
  • 音频焦点、耳机断连、服务停止、TalkBack 和减少动效。
  • 森林 / 雨林先做真素材，来源与授权入 ASSETS.md，之后再扩四景。
  • 计步不能可靠判方向；GPS 放 P2。服务类型参考 Android 官方文档，传感器行为参考 运动传感器文档。

全部 11 条建议、待验证决策与验收边界见 DEVELOPMENT §20。
