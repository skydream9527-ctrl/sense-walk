Product & Engineering Plan · v0.6

慢行SenseWalk

帮助人培养耐心、缓解压力。 先选场景——雨林、森林、沙漠、城市……各有声音与景色身份。 虚走摇杆教你找舒适节奏（拉满≠最快）； 路径有起伏，角色随地形爬坡、跳跃。 关卡从一片黑幕开始，感官与风景随路程展开。满距才通关：不可跳过，不可加速。

1. 产品愿景

用慢感官行走练习耐心与放松。选景定耳目，走路开锁层，满距才通关。急推摇杆、冲地形都帮不了你更快清关。

耐心 · 减压产品目的：培养耐心、缓解压力，而非刷关冲刺。
先选场景大卡片进入；各景声音与景色身份不同。
舒适节奏摇杆甜点区最快；拉满变钝，教你放松。
地形联动路有起伏；爬坡、跳跃贴合场景，宽松不焦虑。
黑幕起笔会话从虚空开始，风景按距长出。
距离即通关未满要求米数不能完成；不可跳过/加速。

2. 开局流程

进入 App 后三步：选场景 → 选模式 → 开始。景色层层展开发生在关卡会话内，选景页不大片剧透完整风景。

01
场景选择 大卡片：雨林 / 森林 / 沙漠 / 城市（及可选夜径）。展示情绪词与要求距离；极弱主题色即可。
02
模式选择 手机控角色（虚走）或户外实走。按需申请计步 / 位置权限。
03
开始关卡 进入会话：黑幕起笔 → 音视振按距解锁 → 满距通关。

3. 双模式行走

手机控角色

Virtual Walk

屏幕虚拟摇杆；舒适甜点曲线；硬顶 ≤ 1.4 m/s。

  • 拉满 ≠ 最快——中段偏转才是舒适步速
  • 无冲刺、无加速条、无倍速
  • 角色走在随距展开的景色与起伏路径上
  • 适合室内 / 先熟悉关卡节奏

户外实走

Real Walk

计步 × 步长为主；可选 GPS；车载暂停。无摇杆。

  • STEP_COUNTER 主路径
  • 「舒适节奏」→ 可选过快平静提示（不惩罚通关）
  • 景色规则相同（可少层，仍从黑幕起）
  • 地形仅作氛围，不要求户外做跳跃操作

4. 舒适节奏摇杆 · v0.6

虚走核心手感：摇杆→速度非单调。中段是甜点；推满反而变慢——用机制教耐心与放松。

屏幕上有一个虚拟摇杆，摇杆拉到最大并不是角色走得最快的时候；玩家需要学会放松，找到一个舒适的节奏。 — 用户需求（忠实并入本版）

摇杆偏转 → 速度（示意）

0静立
~0.3缓行
~0.7 m/s
~0.55甜点
~1.15 m/s
~0.85紧张
~0.95 m/s
1.0拉满
~0.65 m/s

峰值落在偏转 ≈ 0.45–0.65；任意点硬顶 ≤ 1.4 m/s。曲线连续插值，禁止阶跃。不常驻「最佳角度」数值准星，避免变成竞技瞄准。

非单调v(满) < v(甜点)；急推对自己不利。
硬顶不变瞬时 ≤ ~1.4 m/s 步行感；无倍速作弊。
教学文案「推满不会更快。松一点，找舒服的节奏。」
门禁仍在再放松也不能快于距离门禁下界。

虚走 vs 实走

虚走 · 有摇杆

  • 甜点区 = 舒适步行峰值
  • 拉满 = 紧绷变慢
  • 可选短暂「节奏正好」提示（可关）

实走 · 无摇杆

  • 真实步伐累计距离
  • 过快步频 → 可选极轻提示「放慢一点」
  • 不惩罚通关资格；车载仍暂停累计

5. 地形动作 · v0.6

背景路径不是平的。角色动作贴合地形（爬坡、跳跃等）；难度服务正念慢走，不做高压平台闯关。

角色移动的节奏要和地形挂钩：风景里的路不是平的；支持跳跃、爬坡等与地形相关的动作。 — 用户需求（忠实并入本版）
缓坡 / 沙丘上坡攀爬动画 + 自然降速；与「别急」同向。
浅沟 / 路缘轻跳 / 抬脚越过；时间窗宽松。
不平地面步态微调；湿根、落叶、砖缝各景不同。
失败很温柔无扣命；短暂停步后重试；不轰炸失败弹窗。

有效距离会计

有效进度 = 沿路径向前的有效位移（单调前向；卡点/坠落/重试不刷米）
计入沿路径前进；成功过坡/跳后的前进段。
不计入原地踏步、来回刷同一坎、倒走、偏离路径。
减压优先地形鼓励慢看路，不诱发挫败焦虑。
实走简化户外不要求跳跃操作；起伏可作氛围剪影。

分场景气质

场景地形元素典型动作
雨林湿根、缓坡、浅沟攀湿坡、轻跃小沟
森林土坎、落叶坡上坡、越矮坎
沙漠沙丘起伏、软沙费力上坡（自然降速）
城市路缘、缓坡道上台阶感轻跳
夜径石板落差慢步抬脚

6. 距离门禁（不变）

通关 ⟺ 有效距离 ≥ requiredDistanceMeters
不可跳过无跳关；视觉层也不可跳过揭示。
不可加速虚走速度帽 + 甜点曲线；景色不可快进。
不可提前通关未满距结束 = 放弃。
时间≠进度完成态只认有效米数。

7. 景色层层展开 · 继承 v0.5

视觉与音效 / 振动平行解锁：同一距离时间轴，从黑幕到场景风景，一步步丰富。

景色方面也应该层层展开：从一片黑幕开始，然后逐渐有适应场景的风景，比如森林场景的树木、沙漠环境的沙丘等等，一步步逐渐丰富。 — 用户需求（忠实保留）

会话内四拍（示意）

0% · VOID
黑幕纯黑 / 虚空；仅极弱 UI
~10% · ATMOS
氛围形雾、轮廓树、天际线、远景…
~30% · FORM
主体景树干树冠、沙丘、街灯剪影…
~50% · DETAIL
细节藤蔓光斑、落叶、沙纹热浪…
起点 = 黑幕会话开局画面为虚空，不预铺完整风景。
按距展开与音/振同一 atMeters 哲学。
场景适配每景元素不同，不可一套剪影套全关。
会话内发生选景页只留极弱主题色，不剧透。

8. 场景目录 · 声音 + 景色 + 地形

同一套渐解锁，不同的耳目与地形记忆。 换场景 = 换脚步、环境、振动、景色层与路径起伏；门禁与「静/黑 → 响/形 → 振/细节 → 通关」弧线保持一致。摇杆甜点曲线全局共用。

10. 诚实原则

策略做法
速度帽虚走 / 实走限制最大折合速度（≤ ~1.4 m/s）
摇杆诚实拉满变慢是设计，不是隐藏惩罚梗；不包装「加急高级玩法」
车载检测暂停累计，轻提示「好像不是在走」
文案「还需要再走约 N 米」——不说作弊；通关不打操作分
隐私最小权限；位置可选；数据默认本地
视觉诚实不走路则景色不长；满距才是通关
地形诚实有效前进才计距；重试不刷米

12. 验收与开放决策

MVP 验收

  1. 选景 → 选模式 → 开始 ≤ 4 次点击。
  2. 至少雨林 / 森林 / 沙漠 / 城市 四个场景可选，音+视+地形气质独立。
  3. 未满距不可通关；无加速 / 跳过（含视觉揭示）。
  4. 虚走：甜点曲线成立（拉满慢于甜点）；硬顶 ≤ 1.4 m/s；实走可步数通一关。
  5. 各场景层解锁逻辑一致（atMeters）；音色与景色元素不同。
  6. 会话起于黑幕；景色按路程层层丰富，与音/振同一时间轴。
  7. 地形：至少平地 + 坡 + 一种轻跳/越坎；有效前进不刷距。
  8. 文案体现耐心与减压定位。

开放决策

#议题建议
1MVP 是否露出夜径配置保留；可藏「更多」或 Week 4
2模式：独立页 vs 抽屉独立一步更清晰
3虚走操作摇杆（含甜点曲线）；按住可作降级
4实走强制 GPS否
5放弃后续走首版不续，重开清零

7实走景色层数可少层，必须仍从黑幕起

9跳跃：自动 vs 轻点首版偏自动 / 宽窗轻点
