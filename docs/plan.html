Product & Engineering Plan

慢行SenseWalk

从完全静默开始，再逐步长出脚步、环境音与轻微振动。 用「由静到动」的时间轴，帮人把注意力拉回身体与环境——练习耐心，而不是再做一个白噪音播放器。

Week 1 已完成 Android · Kotlin · Compose minSdk 26 · 包名 com.sensewalk.app 文档 v0.2

1. 产品愿景

多数冥想 / 白噪音 App 一打开就满屏声音。慢行反其道而行：前几十秒故意什么都没有。

少即是多首屏只有场景与「开始」，没有打卡与进度条焦虑。
静是默认声音与振动永远逐渐出现，禁止突然满音量。
可随时退出长按结束；不设「坚持才算完成」的惩罚。
无打扰不弹广告、不催分享；会话中可选勿扰。

目标用户

  • 容易分心、焦虑、刷手机停不下来的人
  • 想有一段「什么都不用管」的散步 / 静坐时间
  • 不需要成就、打卡、社群

非目标（首版）

社交 · 成就排行 · 复杂 RPG · 广告 · 强制账号 · 生成式实时音效 · 远程内容商店。

2. 用户旅程

冷启动到开始漫步 ≤ 3 次点击。全程几乎不用操作。

打开 App
首页三张场景卡片，默认选中第一张
点「开始」
进入全屏沉浸会话
阶段 0–3
静默 → 脚步淡入 → 环境音 → 振动（见时间轴）
长按 1 秒结束
或到达建议时长后主动结束
结束页
「你安静地走了 X 分钟」· 再走一次 / 回首页

会话手势

手势行为状态
轻触显示 / 隐藏已用时间✅ Week 1
长按 1 秒结束本次漫步✅ Week 1
单击呼出控制条音量、振动、结束⏳ Week 2
双击立即静音（可保留振动）⏳ Week 3

3. 感官时间轴

以森林漫步为例。各场景 atSec 不同，但叙事相同：空 → 脚步 → 环境 → 触感。

0:00
静默
近黑屏 · 无声 · 无振
故意留白
~0:45
脚步
落叶脚步淡入
8s → 音量 25%
~2:00
环境
虫鸣 / 远鸟
12s → 音量 35%
~3:00
振动
footstep_soft
间隔 ~650ms

设计约束：阶段切换一律淡入；系统静音时降级为「仅振动」；关振动时纯听感仍可用。设置里的静默秒数（默认 60）可缩短「空」的窗口，场景 JSON 的 atSec 控制各层出现点。

8. 音频与素材策略

  1. 优先自采 / 免版税（CC0 / 自有）；无许可不进包。
  2. 响度：耳机小声仍清晰、外放不吓人；统一粗调 LUFS。
  3. 首版不做生成式实时音效；预录循环 + 淡入。
  4. 每轨建议 30–90s 无缝循环；清单维护在 ASSETS.md（待建）。

9. 风险与对策

风险对策
用户觉得「太静、坏了」首次引导文案；设置可缩短静默
机型振动差异大弱/中两档；一键关振动
后台被杀、音频中断前台服务；轻提示勿切走
版权素材清单进仓，无许可不打包
与白噪音 App 同质化强调「由静到有」时间轴
音频档期延误Week 2 先完成调度与 UX

10. 成功标准（MVP）

  1. 冷启动到开始漫步 ≤ 3 次点击。
  2. 至少森林场景完整跑通：静默 → 脚步 → 虫鸣 → 振动。
  3. 任意时刻可结束；结束页只展示时长，无负面文案。
  4. 关振动或系统静音时体验仍可用。
  5. 主路径无崩溃；会话中旋转不重置（或锁定竖屏）。
