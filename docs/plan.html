Product & Engineering Plan · v0.4

慢行SenseWalk

先选一个场景——雨林、森林、沙漠、城市……每个场景有自己的声音身份。 再选虚走或实走，把要求距离走完。感官层仍按路程渐渐解锁：不可跳过，不可加速，不可提前通关。

Week 1 已完成 进度 = 距离 多场景音色 虚走 · 实走 文档 v0.4

1. 产品愿景

选景定音色，走路开锁层，满距才通关。换场景不换规则。

先选场景大卡片进入；各景声音身份不同。
距离即通关未满要求米数不能完成。
不可跳过 / 加速无快进、跳关、倍速。
机制统一所有场景共用 atMeters 渐解锁。
双模式手机控角色或户外实走。
诚实温柔防刷有帽；放弃不羞辱。

2. 开局流程

进入 App 后三步：选场景 → 选模式 → 开始。会话中不可中途换景或换模式。

01
场景选择 大卡片：雨林 / 森林 / 沙漠 / 城市（及可选夜径）。展示情绪词与要求距离。
02
模式选择 手机控角色（虚走）或户外实走。按需申请计步 / 位置权限。
03
开始关卡 进入会话；距离推进该场景的声音与振动层；满距通关。

3. 双模式行走

手机控角色

Virtual Walk

按住前进，松手即停；速度硬顶 ≈ 5 km/h。

  • 无冲刺、无加速条
  • 角色走在该场景色路径上
  • 适合室内 / 先熟悉关卡

户外实走

Real Walk

计步 × 步长为主；可选 GPS；车载暂停。

  • STEP_COUNTER 主路径
  • Fused Location 可选增强
  • 屏幕更空，少盯手机

4. 距离门禁（不变）

通关 ⟺ 有效距离 ≥ requiredDistanceMeters
不可跳过无跳关、广告跳过。
不可加速虚走速度帽；实走过快封顶。
不可提前通关未满距结束 = 放弃。
时间≠进度完成态只认米数。

5. 场景目录 · 声音身份

同一套渐解锁，不同的耳朵记忆。 换场景 = 换脚步材质、环境层与振动气质；门禁与「静 → 响 → 振 → 通关」弧线保持一致。之后还可加海边、雨巷、雪山等。

7. 诚实原则

策略做法
速度帽虚走 / 实走限制最大折合速度
车载检测暂停累计，轻提示「好像不是在走」
文案「还需要再走约 N 米」——不说作弊
隐私最小权限；位置可选；数据默认本地

9. 验收与开放决策

MVP 验收

  1. 选景 → 选模式 → 开始 ≤ 4 次点击。
  2. 至少雨林 / 森林 / 沙漠 / 城市 四个场景可选，配置身份独立。
  3. 未满距不可通关；无加速 / 跳过。
  4. 虚走速度帽；实走可步数通一关。
  5. 各场景层解锁逻辑一致（atMeters），音色不同。

开放决策
