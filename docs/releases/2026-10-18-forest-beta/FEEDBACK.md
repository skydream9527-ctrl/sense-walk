# 阶段测试反馈模板

- Release tag / commit：
- 手机型号 / Android版本：
- 新装或覆盖安装 / 安装结果：
- 场景：森林；模式：虚走 / 实走
- 活动识别权限 / 省电设置（实走相关时）：
- 复现步骤：
- 期望结果：
- 实际结果与发生时米数：
- 复现频率：
- 截图/录屏/错误文字（勿含隐私）：
- 是否阻止继续体验：
- 耗时 / 操作疲劳 / 黑幕等待是否理解：
- 已执行检查：安装 / 暂停 / 放弃 / 恢复 / 完整800m / 锁屏（其余Pending）：

QA补：问题ID、P0/P1/P2、复现build、owner、修复PR/head、回归build/证据与结论。观察、用户报告与已复现实测分别记录；不预填“通过”。
