# 森林阶段包安装与测试

Android 8.0（API26）及以上。下载同一Release的app-debug.apk安装，允许本次安装来源。先记录Release tag；当前App内versionName仍0.1.0-week1/versionCode1，不能仅靠这个名字判断构建。签名/覆盖安装说明见README与release-manifest。若系统确实提示签名冲突，覆盖不了时卸载会清本地会话与设置，先记录测试数据；不要为了测试盲目清数据。

## 先做快速检查

1. 冷启动→森林→虚走，首页其他场景暂未开放符合本次范围。
2. 在屏幕下45%区域按下，向右轻推到舒适位置；森林从黑幕开始，第一层在80m揭示，前期安静与近黑是产品规则。米数可轻触查看。
3. 松手自然减速，停稳后距离/景色不再增长；暂停后立即不前进，恢复等待新输入；放弃有确认且不显示通关。
4. 继续到首个坎附近，观察舒适自动轻跳/紧张站稳提示；提示出现/约3s消失与同局恢复不重复仍需实际证据，不预填通过。
5. 实走允许活动识别权限；拒绝/设备无传感器应有可解释回退，不能卡死或假计步。真实行走记录手数与App前后米数，不假定所有手机传感器一致。

## 完整一局与恢复

- 虚走走到800m才通关；提前结束为放弃。记录耗时/拇指负担，不用加速或调试注入代替完整体验。
- 被动中断后30分钟内重开可选恢复；同会话不重复计距/旧提示；主动放弃或通关后不再弹恢复。
- 实走锁屏15分钟、耳机断连/来电/通知停止、杀进程/重启、大字号/减少动效按条件补测。记录机型/系统/权限/省电设置和实际步骤，没有执行写Pending。

用FEEDBACK.md记录现象、期望、步骤、截图/录屏、发生时米数及build tag。首次安装/启动失败、无故通关、距离持续自增、崩溃、停止后服务不释放优先反馈。无需先测试未开放雨林或四景。
