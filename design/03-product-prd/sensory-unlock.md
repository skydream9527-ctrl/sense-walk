# 感官解锁同程表（音 / 振 / 景）

> 机制与场景无关：同一叙事弧，换音色、视觉元素、地形事件与里程碑米数。  
> **耳目同程** — 禁止只开声音不开景色，或一键铺满视觉。

---

## 1. 相对进度总轴

| 相对进度 | 听觉 / 触觉 | 景色（视觉） |
| --- | --- | --- |
| 0% | 静默 | **黑幕 / 虚空** |
| ~10% | 该场景脚步淡入（步频同步） | 第一层氛围形 |
| ~30% | 该场景环境淡入 | 主体景物 |
| ~50% | 该场景振动（步频同步） | 细节丰富 |
| ~75%（v0.7） | 深层远音（远雷/远鸟/风沙/钟声/夜风） | 远景生命与透光变化 |
| ~95%（v0.7） | 环境层轻轻收窄（抵达前宁静） | 终点意象隐现（幽径/空地/绿洲/长椅/石阶） |
| 100% | 可通关 | 景色保持完整（不切屏炫技） |

停走 → 进度停。淡入用 `fadeMs`（音）/ `fadeMeters`（视）插值，避免一步跳变。

## 3. 禁止项（感官）

| 禁止 | 原因 |
| --- | --- |
| 选景页预播完整风景 | 剧透过程奖励 |
| 会话内「显示全部景色」 | 等同跳过 |
| 用时间或手势跳过视觉相位 | 破坏距离门禁哲学 |
| 音视进度脱钩（长期只听不见） | 破坏耳目同程 |
| 城市层吵杂超限 | 减压失败 |

---

## 4. 配置字段（权威）

- `requiredDistanceMeters`  
- `phases[].atMeters`（迁移期可双读旧 `atSec`）  
- 视觉：`layer: "visual"` 或 `visualPhases[]`  
- v0.6：`pathProfile`、`stickCurveId`（默认 `comfort_v1`）  

原则不变：**音视同源 atMeters，黑幕起笔，逐步丰富。**
