# 信息架构

## 站点地图

```
App
├─ Home（场景大卡片列表）
│   ├─ 雨林 / 森林 / 沙漠 / 城市
│   └─ 〔更多〕夜径（可选）
├─ Mode Select（选景之后）
│   ├─ 手机控角色 · 虚走
│   └─ 户外实走
├─ Session
│   ├─ 黑幕 / 景色层合成
│   ├─ 旅人 + 地形（虚走）
│   ├─ 舒适摇杆（虚走）/ 无摇杆（实走）
│   ├─ 极简 HUD：米数、可选用时
│   ├─ 长按 → 放弃确认
│   └─ 满距 → 通关
├─ Clear（通关页）
│   └─ 场景名 + 米数 + 用时 → 回 Home
├─ Abandon（放弃）
│   └─ 温和文案 → 回 Home
└─ Settings
    ├─ 步长
    ├─ 振动开关
    ├─ GPS 辅助（默认关）
    └─ 节奏提示（默认：短暂一次 / 可关）
```

## 导航规则

| 规则 | 说明 |
| --- | --- |
| 先选场景再选模式 | 不可颠倒 |
| 会话中无换景/换模式 | 须放弃后重来 |
| 设置可从 Home 进入 | 会话中设置入口克制或只读 |
| 返回手势 | 会话中触发放弃流程，不直接杀进程丢状态而不提示 |

## 页面优先级（MVP）

P0：Home · Mode · Session · Clear · Abandon  
P1：Settings  
P2：夜径入口、本地统计  

## 内容层级（选景卡）

1. 场景名  
2. 短情绪词（≤ 8 字）  
3. 要求距离  
4. 极弱主题色  
5. **不出现**完整风景、星级难度、预估「刷分」  

## 会话 HUD 层级

1. （底层）景色合成  
2. 旅人与路径  
3. 米数 / 轻触显隐用时  
4. 摇杆（虚走）  
5. 放弃（长按区域，低对比）
