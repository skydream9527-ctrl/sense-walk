## 1. 愿景与目标

### 1.1 愿景

培养耐心、缓解压力：用「走完一段有感官身份的路」练习放松——急无用，满距才到。

### 1.2 成功长什么样（温柔指标）

| 指标 | 定义 | 备注 |
| --- | --- | --- |
| 会话完成率 | 开始会话中最终通关的比例 | **主指标**；不羞辱未完成 |
| 中位有效步行节奏 | 虚走甜点区停留时长占比 | 反映是否学会放松 |
| 放弃后 7 日回访 | 放弃用户是否自愿再来 | 文案与体验是否够温柔 |
| 场景重复选择多样性 | 非单一场景垄断 | 身份是否成立 |
| **不做** | 连续打卡羞辱、全球排行、通关速度榜 | 反设计 |

## 2. 目标用户

| 画像 | 需求 | 非需求 |
| --- | --- | --- |
| 压力大的成年人 | 短-中时长（12–20 min）可完成的安静体验 | 竞技刺激 |
| 想培养耐心的人 | 规则诚实：急了反而慢 | 跳过道具 |
| 散步/正念边缘用户 | 虚走室内也可；实走可出门 | 强制社交分享 |

**非目标用户（本阶段）**：硬核速通玩家、排行榜驱动型、儿童向教育课纲（可日后另议）。

## 3. 用户故事

### P0

1. 作为用户，我能在首页看到场景大卡片（名称、短情绪词、要求距离、极弱主题色），以便先选我想待的地方。  
2. 作为用户，选景后我能选择虚走或实走，再开始；中途不能偷换。  
3. 作为虚走用户，我用摇杆前进，并发现**拉满不是最快**，中段更舒服。  
4. 作为用户，会话从黑幕开始，走得越远，该景的声音与景色越丰富。  
5. 作为用户，只有走满 `requiredDistanceMeters` 才能通关；未满长按为放弃。  
6. 作为用户，路径有缓坡与轻跃，失败可重试且不扣命、不刷距。  

### P1

7. 作为实走用户，我用计步完成同一门禁与景色规则；过快仅轻提示、不取消资格。  
8. 作为用户，我能在设置里调节步长、振动、GPS 辅助、节奏提示开关。  
9. 作为用户，首次虚走能看到温和教学：「推满不会更快」。  

### P2

10. 作为用户，我可以遇到可选夜径。  
11. 作为用户，旅人可有极轻场景着色/变体。  
12. 作为用户，本地可看累计米数（无排行）。

## 5. 关键流程（摘要）

```
进入 App
  → ① 场景选择
  → ② 模式选择
  → ③ 开始 → 权限（按需）→ Session
       → 黑幕起笔 → 按距解锁 → 地形动作（虚走）
       → 满距 → 通关页
       → 长按 → 放弃（温和）
```

冷启动到开步 ≤ **4** 次有效点击。详规见 [`../04-interaction-mockups/flows.md`](../04-interaction-mockups/flows.md)。

## 6. 硬规则表（继承，v0.8 补能力边界）

| 规则 | 说明 |
| --- | --- |
| 进度 = 有效距离 | 不是已过时间 |
| 通关条件 | 有效距离 ≥ `requiredDistanceMeters` |
| 禁止跳过 | 无跳关/广告跳过；视觉层也不可跳过揭示 |
| 禁止加速 | 无倍速；景色不可快进铺满 |
| 禁止提前通关 | 未满距结束 = 放弃 |
| 舒适摇杆 | \(v(1) < v(d^*)\)，\(d^*\approx0.55\)；硬顶 ≤ 1.4 m/s |
| 拉满≠最快 | 紧张区回落；拉满明显慢于甜点 |
| 无常驻数值准星 | 「正好」提示最多短暂，可关 |
| 景色黑幕起笔 | 仅会话内展开；选景页不剧透 |
| 耳目同程 | 同一 `atMeters` 哲学 |
| 双模式 | 会话中不可切换场景/模式 |
| 地形减压 | 不扣命、宽松、重试不计刷距 |
| 虚走倒走/刷坎 | 不计有效距离；纯计步实走无法可靠辨别方向/原地踏步 |

### 舒适曲线摘要

| 区间 | d | v 示意 |
| --- | --- | --- |
| 静立 | 0 | 0 |
| 缓行 | 0.15–0.35 | ~0.5–0.9 |
| **甜点** | **0.45–0.65** | **~1.05–1.20** |
| 紧张 | 0.75–0.90 | ~0.85–1.0 |
| **拉满** | **1.0** | **~0.55–0.75** |

## 8. 权限与隐私

| 权限 | 何时 | 用途 |
| --- | --- | --- |
| `ACTIVITY_RECOGNITION` | 实走开始时 | 计步 |
| 位置（精细/粗略） | **仅**用户开启 GPS 辅助 | 仅辅助步长校准，不直接计入进度；P2，可关 |
| 振动 | 常规 | haptic 模式 |
| 网络 | MVP **不需要**联网游玩 | 无账号墙 |

**隐私原则**：

- 数据默认本地；不做服务器反作弊  
- 不上传轨迹社交网络  
- 文案诚实说明权限用途  
- 无计步器时引导虚走，不骗进度

## 11. 验收标准（MVP）

对齐 DEVELOPMENT §16：

1. 选景 → 选模式 → 开始 ≤ 4 次点击  
2. ≥ 4 主场景可选，各有音+视+地形气质配置  
3. 未满距不可通关；无加速/跳过（含视觉）  
4. 虚走甜点成立（拉满慢于甜点）；硬顶 ≤ 1.4；实走可步数通一关  
5. 场景切换时 atMeters 层逻辑一致  
6. 会话起于黑幕；景色按路程丰富  
7. 地形：平地 + 坡 + 一种轻跳/越坎；有效前进不刷距  
8. 通关/放弃文案合格；产品文案体现耐心与减压  
9. 停走不涨距、不长景色；脚步音不继续循环  
10. 实走锁屏 15 分钟继续计步/播放/相位推进；中断恢复不重复通关  
11. 时长按模式校准；主计划 S1–S9 单测通过
