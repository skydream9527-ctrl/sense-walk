# SW-012 r1 · 雨林五层素材制作提示词（交付 MiniMax / SW-006）

本文件是可追溯的生产输入，不代替真实素材。MiniMax 在 SW-012 设计经 Antigravity **approved_design** 后据此制作候选（SW-006），仍须按 `docs/collaboration/contracts/visual-assets.md` 独立验收（候选最多声明 `candidate`，批准来自 Antigravity）。素材 manifest 必须用 `design_ref` 引用批准 handoff 与本 spec 的确切 sha256。

> 命名状态：五层 layer ID 目前为 **proposed**，以 Antigravity 冻结后的 `design-spec.json` 为准；若冻结时改名，MiniMax 按冻结名交付，不自行改名。

## 0. 所有层共用约束

- 设计依据：`design/05-visual-design/SW-012/r1/design-spec.json`（画布/锚点/色板/相位/proposed id）。
- 统一风格参考：`previews/rainforest_style_reference.png`（875m 终景）、`previews/composition_guide.png`（色板/构图/雨林 vs 森林）、`previews/layer_map.png`（五层分层标注）。
- 场景身份单页：`design/01-scenes-terrain/rainforest.md`（§2 色板、§4 时间轴）。
- 画布：1080×1920，PNG 真实 RGBA 透明；坐标归一化 0–1。
- 光源：统一**右上**（俯角 12–20°），所有层方向一致；共享脚底基线 y=.865。
- 旅人锚点 x=.34、脚底 y=.865（程序绘制，**不要在任何素材里画人**）。
- 下方 45%（y=.55–1.00）是摇杆触控区：湿雾低对比、干净，**不烘焙**任何按钮/文字/图标/摇杆/米数/暂停标志。
- 透明：林隙、树间、藤蔓间隙、光与辉光之外一律真透明 alpha=0；**禁止**黑色/深色矩形底、白边、抠图光晕、投影硬边。
- 色板（雨林单页为主）：void `#050807`、雾 `#1A2E28`（亮雾 `#2F4E44`）、树干树冠 `#1E3D36→#2A5248`、藤蔓光斑 `#C4D4A8`；派生：板根暗部 `#162E28`、前景最暗 `#122621`、阔叶 `#1C4236/#33604F/#4A6B4F`、苔藓 `#60764A`、藤 `#3A5C4C/#6A8A60`、林隙柔光 `#A8C9A6`、水气湿面 `#5A7D72`、幽径 `#9FC09A`、湿径 `#3A584C`。**不要使用森林暖褐 `#A89060`、干叶色、干爽土褐色，不要高饱和。**
- 风格：安静二维插画、干净剪影、低饱和冷湿绿、柔和漏光、雾气包裹感、适量暗部留白；**潮湿浓绿雨林**，不是通透干爽落叶林。
- 输出：每层一张独立 PNG，只画该层内容；**不把六阶段预览的层透明度烘焙进 RGB/alpha**（每层按其自身完整不透明度出图，运行时由 app 按米数衰减）。
- 拼接：本轮全部 `tileable=false`，不要求无缝平铺；左右构图留出右侧溢出（按高度铺满、左对齐、右侧溢出宽度内有限横向视差），关键主体收在中央 80% 安全宽。
- 通用负提示（每层都附加）：
  `棋盘格, 方格, 同心环, 重复几何纹理, 32px/8px 对角网纹, 马赛克, 噪点颗粒, 矩形底色, 硬边抠图, 白边, 描边外发光, 文字, 水印, logo, UI, 按钮, 图标, 人物, 旅人, 建筑, 道路指示牌, 高对比, 霓虹, 闪光, 雷暴, 闪电, 恐怖元素, 惊吓, 暖褐色调, 干叶, 干爽土路, 落叶林, 鸟群, 斜射长条光束, HUD`

## 1. mist（overlay，parallax 0，90m，目标 opacity .55，fade 20）

- 参考：`exports/rainforest_mist.png`、`previews/layer_checks/rainforest_mist_{black,white,magenta}.jpg`、`previews/zoom/rainforest_mist_zoom.png`、`source/svg/rainforest_mist.svg`。
- 主体：第一层氛围雾。画面下部一条横向铺开的**贴地湿雾**（大扁椭圆软光，重心约 y=.79），左下角一团略亮的雾心托住旅人脚底；中景三缕横向飘雾（高低错落、大柔化、收在屏内）；上部可有极薄的一层空气雾。全部是冷雾青 `#1A2E28/#2F4E44` 的低不透明度柔渐变，感觉潮湿、缓慢、可呼吸。
- 透明：雾团以外全部真透明；雾的恒定不透明区不得压到任何屏边，边缘 alpha 平滑归零，**无水平硬切线、无矩形底**。
- 禁画：树干、树叶、藤蔓、光柱、地面路径、人物、整片背景填充、任何纹理/网格。
- 正向提示：
  `安静二维扁平插画，雨林贴地湿雾与几缕横向飘雾，冷雾青绿色 #1A2E28/#2F4E44 很低不透明度，边缘完全柔化融入全透明，左下角一团略亮雾心，潮湿空气感，无硬边无矩形底无纹理，背景纯透明，竖构图 1080x1920，大面积暗部留白，宁静`
- 边缘/裁切：黑/白/洋红三底上都只能看到柔雾、看不到矩形边界；本设计稿四边 strip4 实测 max alpha≤12、无 alpha≥64 实色边，正式素材应达到同等软度。
- 自检：三底目检无矩形底/白边；放大雾心与四缘无周期纹理。

## 2. trunks_canopy（parallax 0.30，270m，目标 opacity .85，fade 25）

- 参考：`exports/rainforest_trunks_canopy.png`、三层底检查图、`previews/zoom/rainforest_trunks_canopy_zoom.png`、`source/svg/rainforest_trunks_canopy.svg`。
- 主体：雨林主体景。约六根**带明显板根扩张的粗壮湿干**（底部向外张开，区别于森林细高树干），粗细高低错落、微摆；竖向体积渐变（两端 `#162E28` 没入暗部、中段 `#1E3D36` 受光），最右一根 `#122621` 前景最暗纯剪影；右上细边光；树干中上段贴几片极低 α 苔藓柔斑 `#60764A`。上方**三排连片阔叶顶棚**（`#1C4236/#2A5248/#33604F` 由深到亮，大叶团簇层叠、冠缘有垂叶串），顶棚在上中部**刻意留两处林隙**（约 x=.54–.68 与 x=.17–.26），上缘透光留给第 4 层。
- 透明：两处林隙、树间、冠线以上、地面以下真透明；整体靠纵向 mask 从黑幕淡入、到地面前淡出（**不画地面**）。
- 禁画：干叶土坡、土路、藤蔓（归第 3 层）、漏光光束（归第 4 层）、鸟、人物、第二套树林、树皮照片纹理、矩形底。
- 正向提示：
  `安静二维插画，雨林深处数根带巨大板根的粗壮湿润树干，竖向柔和明暗渐变，右上微妙边光，少量苔藓质感，上方连片层叠的巨大阔叶树冠形成顶棚并留出两处不规则天空缺口，低饱和冷湿墨绿 #1E3D36/#2A5248/#1C4236，树间与林隙真透明，背景纯透明无填充，竖构图 1080x1920，浓密但暗部有呼吸留白，无地面无人物`
- 边缘/裁切：树干可超出顶部；横向铺满略超宽；林隙边缘是柔叶轮廓不是几何洞。
- 自检：三底上板根/冠缘干净无矩形底；林隙位置与第 4 层漏光呼应；无等距条纹/棋盘。

## 3. vines_light（parallax 0.60，450m，目标 opacity 1.0，fade 25）

- 参考：`exports/rainforest_vines_light.png`、`previews/zoom/rainforest_vines_light_zoom.png`、`source/svg/rainforest_vines_light.svg`。
- 主体：前景细节层。约 8 条自顶棚垂落的**弯曲垂藤**（藤身 `#3A5C4C`，两端可超出画布宽，最长止于约 y=.39，**不进入下 45% 触控区**），藤上对生小叶（`#6A8A60/#33604F`），藤尖可有少量克制水珠（`#5A7D72`）；藤间与冠隙散布约 20 个**藤蔓暖绿光斑**（`#C4D4A8` 柔化圆斑，是叶隙漏下的点状暖绿光，不是长光束）。垂藤避开旅人 x=.34 竖线。
- 透明：藤蔓、叶、光斑以外全部真透明；光斑柔边衰减。
- 禁画：树干顶棚主体（归第 2 层）、成束斜射光、鸟、人物、文字 UI、矩形底、串珠式等距重复斑点。
- 正向提示：
  `安静二维插画，雨林前景从画面顶部垂下的数条细长弯曲藤蔓与对生小叶，藤尖少量水珠，藤叶之间散落柔和的暖绿色点状光斑 #C4D4A8（叶隙漏光，圆形柔斑非光束），低饱和湿绿 #3A5C4C/#6A8A60，藤蔓集中在画面上中部不到一半，下方留空，藤蔓与光斑之外纯透明，竖构图 1080x1920，干净，空气湿润`
- 拼接：`tileable=false`，不做无缝；左右两端可让藤蔓出画，右侧留视差溢出。
- 自检：三底上藤线边缘干净、光斑无硬圈；垂藤不压旅人竖线、不落触控区。

## 4. distant_glow（overlay，parallax 0，675m，目标 opacity .85，fade 25）

- 参考：`exports/rainforest_distant_glow.png`、三层底检查图、`previews/zoom/rainforest_distant_glow_zoom.png`、`source/svg/rainforest_distant_glow.svg`。
- 主体：**林隙透光 + 流动水汽**。三团近竖椭圆的**斑驳漏光**（主团在 x≈.61/y≈.16，次团 x≈.21/y≈.19，一小团右上；位置与第 2 层顶棚两处缺口呼应），`#A8C9A6` 低不透明度、大柔化、末端归零——这是雨林冠隙漏下的柔和光斑，**不是**森林那种从右上到左下的长斜光束；中下部三条横向拉长、左右错开的极淡水汽柔带（`#5A7D72/#2F4E44`，α 很低），表现湿气流动。
- 透明：除三团渐隐漏光与水汽带外全部真透明；恒定不透明区收在屏内。
- 禁画（强化）：长梯形/多边形光束硬边、光束轮廓线、放射光线阵列、十字星芒、镜头眩光、第二套树林或背景、天空填充、远鸟、棋盘/方格/同心环/重复网纹、矩形底、文字人物。
- 正向提示：
  `极简安静的雨林冠隙漏光，两三团近椭圆的柔和斑驳光斑从顶棚缺口透下，淡暖白绿 #A8C9A6 很低不透明度，边缘完全柔化融入黑色，无直线无几何边界，下方几缕横向极淡青绿水汽，背景纯透明无任何填充，竖构图 1080x1920，干净，潮湿空气感，无长斜射光束无鸟`
- 边缘/裁切：黑底上看不到任何矩形边界；漏光位置必须与 trunks_canopy 林隙对齐构图。
- 自检（必须过）：三底目检无方格/环纹/矩形底/硬边光束；放大漏光中心与边缘无周期纹理；本设计稿该层四边 strip4 实测 alpha 全 0。**目检不可用统计阈值替代。**

## 5. glade（overlay，parallax 0，855m，目标 opacity .90，fade 20）

- 参考：`exports/rainforest_glade.png`、三层底检查图、`previews/zoom/rainforest_glade_zoom.png`、`source/svg/rainforest_glade.svg`。
- 主体：终点幽径（**900m 不切屏炫技**）。画面中下部一团安静的**幽径辉光**（椭圆径向，`#9FC09A`，中心约 x=.56/y=.60，峰值低、四边平滑归零）；一条自画面底中偏右收窄、通向辉光的**湿径**（`#3A584C` 柔带 + `#5A7D72` 冷青湿面微光 + 两三处横向反光），湿径上下缘都淡出，**屏底 alpha=0**。氛围是湿润泥土反光、将至空地的宁静，不是干爽土路。
- 透明：辉光/湿径以外全透明；中心到边缘连续平滑到 alpha=0。
- 禁画（强化）：同心圆环、光圈、放射光线、第二套树林、干叶、干爽土路、道路标线/脚印、棋盘/方格/对角网纹、矩形底、亮斑阵列、文字人物、终点大门/建筑/闪光庆祝。
- 正向提示：
  `极简单一柔和径向辉光，雨林深处一条湿润反光的小径通向一团安静淡绿光 #9FC09A，冷青湿面微光 #5A7D72，椭圆辉光中心柔和最亮、边缘无缝淡出到全透明，小径上下缘淡出、画面底边无硬边，无环无光线无纹理，背景纯透明，竖构图 1080x1920，大面积暗部留白，宁静，将至终点但不炫技`
- 自检（必须过）：三底目检只有一团平滑光+一条湿径、无环无纹；屏底无矩形切线（设计稿底边 strip4 max alpha=4）；叠加到 875m 终景无任何周期性网纹。

## 6. 阶段合成与交付提醒（MiniMax）

- 六阶段检查图按 **fade 完成点**取值：0 / 110 / 295 / 475 / 700 / 875m（即解锁点 90/270/450/675/855 各加 fade；最后 875m ≤ 900m 终点）。void 与旅人按程序绘制，不要把人画进素材，不要把阶段透明度烘焙进单层。
- 0m 必须纯黑幕（除程序旅人外无风景提前揭示）；900m 景色保持完整、不切屏、不闪光。
- 候选目录：`design/assets/rainforest/candidates/<task-id>/r<revision>/`，含 `png/ webp/ checks/{black,white,magenta}/ checks/stages/ checks/zoom/ manifest.json`（以 visual-assets 契约现行模板为准）。
- 每层 ≤400KB、五层合计 ≤2MB（webp 入包预算）；宽目标 1080，记录真实原始尺寸，不得放大低分辨率素材冒称原生 1080。
- manifest 每层记录 layer_id/file/sha256/width/height/bytes/alpha_channel/render_role/tileable/origin/process/quality_status/checks/limitations，并在包级 `design_ref` 写明：设计任务 SW-012、批准 handoff 路径、`design-spec.json` 路径与其 spec_sha256；`origin` 写明生成服务与条款，**不得标 CC0**；API 账本如实记成功/失败/费用，未知写 unknown。
- `tileable=false`：不要提供或宣称无缝平铺；当前渲染语义仅右侧溢出宽度内有限横向滑动（390×844 溢出 85px、1080×2400 溢出 270px，恒可见源带 x[216,864]，旅人锚点源 x=367 必须恒可见）。
- 批准前候选状态只能是 `candidate`；设计批准（SW-012）与素材批准（SW-006）是两道独立审核；设计若出新 revision，旧引用失效需重审。
