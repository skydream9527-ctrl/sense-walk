# SW-017 R1 · 森林 800m 逐项验图清单

- 适用范围：森林 800m 虚走（浮动摇杆）/实走（前台计步）双模式，当前 main 生产素材（SW-010 验收入包的五层 webp）+ 当前渲染链。
- 参照根目录：`design/05-visual-design/SW-017/r1/`；除 `previews/real_captures/` 外全部为**设计模拟**，只用于约定「应该核对什么、长什么样算对」，不是 App 截图、不是真机证据。
- 判定方分两类：**[素材]** = MiniMax 候选层核对（候选阶段，静态图即可判定）；**[设备]** = ZCode 真实 App / Antigravity QA 必须在模拟器或真机取证后判定，设计模拟不能替代。
- 取证最低要求：截图/录屏附带 head SHA、设备分辨率与 density、米数/状态、模式；停走类行为需间隔连拍或录屏。缺陷判定与最终接受归 Antigravity，Trae 不自批。

## A. 素材层静态核对 [素材]

在候选评审阶段对单层导出做，与是否入包无关。当前五层已 SW-010 验收，本节用于 SW-006 雨林候选与未来森林返工候选。

| ID | 检查项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| A1 | 纯黑起步语义 | 0m 参照 `matrix/*_000m` 格 | 第一层揭示前（森林 <80m）只有 Void #060806 与程序旅人；素材本身不承担 0m 画面 |
| A2 | 三底检查 | 单层贴黑/白/洋红三底目检 | 无白色矩形底、无黑矩形底、无烘焙的纯色背板；边缘在洋红底上不出现脏边 |
| A3 | alphaMask 边缘 | 看 alpha 通道（或洋红底）四缘 | 四边无 alpha≥64 的实色硬边；外缘不亮于内邻；**注意：当前森林入包层右/左缘是 30 列全透明硬切（见 D5），候选不应沿用此切法** |
| A4 | 无棋盘/同心环 | 中央与四缘 2× 放大 | 无 AI 棋盘格、同心环、重复接缝、生成水印与签名 |
| A5 | 内容不越触控区 | 叠 55%/45% 分区线对拍 `zones/` | 高对比主体不进入下 45%；不压旅人竖线 x=.34 |
| A6 | 不画旅人/UI | 单层目检 | 素材不含人物、摇杆、米数、按钮 |
| A7 | 五层配准 | 五层按 anchor 叠加终景 | 树干/树冠/光路/空地透视一致，无互相打架的地平线；留白与光束位置符合设计稿 |
| A8 | 尺寸与透明 | 候选 manifest | 768×1376 RGBA（森林现状）；按高 cover 后宽向必须覆盖目标屏，**右缘不得留全透明列**（D5 教训：至少需覆盖 1080×2400 cover 宽 1340px 的安全余量） |
