# SW-021 r1 · 森林连续视差三层可平铺素材制作提示词（交付 MiniMax）

本文件是可追溯生产输入，不代替真实素材，也不代表设计已批准。本 spec 当前为 `design_candidate`；MiniMax 候选最多声明 `candidate`，Antigravity 独立批准设计、并按 `docs/collaboration/contracts/visual-assets.md` 验收素材后才可入包。ZCode 的接线说明在 `README.md` 与 `design-spec.json.tile_rendering_contract_for_zcode`，不要据本文件改 app。

本轮**只做三层**：`tree_outline`、`tree_trunks`、`leaf_path`，全部 `tileable=true, repeat-axis=x`。`light_shows` 与 `clearing` 复用 SW-010 已验收入包 webp，**不要重画、不要改字节**。雨林（SW-012/D-009）不在本轮，`tileable=false` 不变。

## 0. 三层共用约束

- 设计依据：`design/05-visual-design/SW-021/r1/design-spec.json`（canvas/tile 元数据/色板/相位/接缝数值）。
- 逐图层参考（必看，先于任何生成）：
  - 设计 tile：`previews/tiles/forest_{layer}_tile.png`（1080×1920 RGBA）
  - 可编辑结构：`source/svg/forest_{layer}_tile.svg` 与 `source/sw021_tile_model.py`（图元坐标/团簇/树干布局的权威结构）
  - 三底检查：`previews/tiles/checks/forest_{layer}_check3.png`
  - 三次拼接：`previews/tiles/repeat/forest_{layer}_repeat3.png`
  - 接缝探针：`previews/tiles/seam/forest_seam_probe_sheet.png`
  - 阶段合成：`previews/composite/forest_tiled_matrix_1080x2400.png`（看该层在六阶段中的角色）
- 画布：**1080×1920 px，PNG 真实 RGBA 透明**；这是原生目标规格，禁止把 768×1376 旧 webp 放大后冒称 1080。
- 平铺：`repeat-x`（仅水平）。垂直方向不平铺：树干/冠线允许超出上缘、地面只占下部。
- 接缝安全区：孤立硬边缘主体（整棵树干、大团簇中心）距离 x=0 与 x=1080 两条缝 ≥96px；需要跨缝的软元素（树冠团块、叶斑、边光）按下方「接缝条件」成对绘制。
- 光源：统一**右上斜射**，与已批准 `light_shows` 光束方向一致；三层共享同一地平线与脚底基线（归一化 y=.865）。
- 锚点：旅人 x=.34、脚底 y=.865 由程序绘制，**任何层禁止画人/人影**；下 45%（y=.55–1.00）中央触控带 x≈.28–.71 保持低对比、干净。
- 色板（契约六色为主 + 允许的派生色，见 design-spec `palette`）：void `#060806`、轮廓 `#1A2820`（后排 `#22332A`、受光 `#26382E`）、树干 `#2D4A3E`（暗部 `#244036`、前景 `#243A30`）、林光 `#8FA87A`、落叶 `#6B8F71`、暖褐 `#A89060`、土 `#4A4030→#312A1F`、空地微光 `#A8C5A0`。**不得引入新色相、不得高饱和。**
- 不烘焙透明度：每层按自身完整不透明度出图；运行时由 app 按 80/240/400m 与 opacity .60/.70/.80 二次衰减。
- 不烘焙终景：禁止奶白/亮绿大圆盘（旧 `tree_trunks.webp` 的问题），终景亮度只能来自复用的 `clearing` 层。
- 风格：安静二维插画、干净剪影、低饱和、柔和林光、适量留白；**干叶通透的落叶林**，不是湿雾雨林。
- 通用负提示（三层都附加）：
  `棋盘格, 方格, 32px/8px 对角网纹, 同心环, 重复几何纹理, 周期噪点, 马赛克, 矩形底色, 硬边抠图, 白边, 描边外发光, 接缝处亮线/暗线, 文字, 水印, logo, UI, 按钮, 图标, 人物, 旅人, 人影, 建筑, 路牌, 高对比, 霓虹, 闪光, 雨, 浓雾, 雨林阔叶, 藤蔓, 苔藓湿面, 恐怖元素, HUD, 天空渐变, 雾底层`
- 预算（正式素材）：单层 webp ≤400KB；本层与另两层 + 复用两层合计 ≤2MB/景。

### 接缝条件（三层统一验收口径）

1. 数学无缝优先：先在 **3240×1920（3 个 tile 宽）** 画布上画全部内容，所有跨缝图元按完整形态画一次并允许跨越 1080/2160 两条线，再把三段 `[-1080,0]`、`[0,1080]`、`[1080,2160]` 以 `over` 折叠回中央 tile。任何跨缝树干/团块/叶斑都能完整拼回，不留缺口。
2. 连续函数：冠线/地面上缘在缝两侧的 **y 值与斜率都连续**（地面用整周期正弦，1 或 2 周/tile，禁止任意非周期曲线）。
3. 密度连续：叶斑/小团簇在缝两侧各 96px 内的数量、明度分布一致；随机元素用固定种子在 3W 周期坐标上发射，不要在单 tile 内独立撒点。
4. 像素自检（参考设计稿实测口径，正式稿同法复测）：左右相邻两列的逐像素差均值应与 tile 内部相邻列自然差同量级；设计稿数值：trunks 均值 0.025/最大 1，leaf_path 0.003/最大 3，outline 0.218（个别抗锯齿像素最大差 255 但无可见缝）。**像素统计只作排查，最终以三次拼接 + 多偏移视口目检为准。**
5. 目检必过：`tile+tile+tile` 横拼在黑/白/洋红三底上无亮线、暗线、缺口、重影；再以水平偏移 0/270/540/810px 四个视口查看，均看不到缝。

## 1. tree_outline（parallax 0.30，80m，opacity .60，fade 20，tileable=true）

- 参考：`previews/tiles/forest_tree_outline_tile.png`、`source/svg/forest_tree_outline_tile.svg`、check3、repeat3、seam probe。
- 主体：远处**两排**落叶林冠线。后排更冷更虚（`#22332A`），前排略实（`#1A2820`，少量受光团块 `#26382E`）。柔圆团簇、团簇数量克制（参考 SVG 实际团簇数，不要加密成云墙）；前排团簇高低差明显、留出 **两处明确大林窗**（真透明，能看到 void 黑）。
- 结构改进（相对旧 cover 整幅山水画）：冠线只占中下部一条横向起伏带（参考 tile 实际 y 区间）；冠线以上、团簇之间、画面下缘全部真透明，靠柔和纵向衰减融入。
- 着色规则：同色团簇必须 **union mask 整体着色**——先把同层团块合并成一张蒙版再统一填色/加渐变；受光用整组 clip 叠柔光。禁止逐个半透明圆叠加（会产生深浅「泡泡」边界）。
- 接缝：团簇可跨缝，按 3W 折叠法绘制；缝两侧冠线 y/斜率连续；林窗不得正好落在缝上。
- 禁画：竖树干、枝桠细节、地面、土坡、光柱、鸟、亮盘、整片背景填充。
- 正向提示（如用生图工具时的核心描述，可零 API，见 §4）：
  `安静二维扁平插画，远处落叶林树冠剪影两排，柔圆重叠阔叶团块，水平起伏林线带两处大透明林窗，低饱和深墨绿 #1A2820 与冷绿 #22332A，团块整体着色无重叠泡泡边界，边缘轻微柔化，树间真透明，水平无缝平铺（repeat-x tile 1080x1920），缝两侧树冠高度与斜率连续，画面上半部与下缘纯透明，无地面无树干无天空，竖构图，留白通透`
- 自检：三底只见冠线无矩形底；repeat3 + 四偏移视口无缝、无周期性云墙；林窗处为真透明。

## 2. tree_trunks（parallax 0.30，240m，opacity .70，fade 25，tileable=true）

- 参考：`previews/tiles/forest_tree_trunks_tile.png`、`source/svg/forest_tree_trunks_tile.svg`、check3、repeat3、seam probe。
- 主体：每周期 **5 根**中景树干，**错落微锥**（粗细差约 5:1，轻微摆幅，不要等距等高蜡烛排列），保留 **2 处大林窗**；其中 **1 棵巨树完整跨缝**——在 x=0 与 x=1080 处各露出同一棵树的左右两半，3W 折叠后拼回完整一棵（repeat3 中表现为每隔 1080px 一棵完整巨树）。
- 体积：全部树干**从画面上缘之外伸入**（顶端在屏外，无硬切口、无蜡烛平头），顶部由黑暗渐变进入、底部在触到地面前淡出；**不画地面**。竖向渐变暗部 `#244036`、受光 `#2D4A3E`，右上一道很细边光 `#8FA87A`（低 alpha）；可有一根最暗前景剪影 `#243A30`。
- 历史问题（必须避免）：入包旧 `forest_tree_trunks.webp` 烘焙了奶白终景圆盘、且是整幅构图无法平铺。禁止任何亮盘/辉光出现在本层；空气光最多极弱大柔斑，且不得形成第二背景。
- 接缝：跨缝巨树的轮廓、渐变、边光在缝处严格连续；其余树干中心离缝 ≥96px。
- 禁画：第二套树林、树皮照片纹理、地面/落叶、光柱、亮盘、鸟、文字人物、矩形底、等距条纹。
- 正向提示：
  `安静二维插画，5 根高耸微锥落叶林树干错落分布，粗细对比强烈、轻微自然弯曲，全部从画面顶部屏外伸入、顶端融入黑暗、底部触地前淡出，竖向柔和明暗渐变，右上方极细边光，一根最暗前景树剪影，其中一棵巨树在左右边缘完整跨缝可水平无缝拼接，低饱和墨绿 #2D4A3E/#244036，树间真透明无填充无地面无亮盘，repeat-x 无缝 tile 1080x1920，竖构图，极简留白`
- 自检：三底树干边缘干净无矩形底；repeat3 中跨缝巨树完整闭合、无重影；缝差与自然差同量级；竖斑为自然结构不是等距条纹。

## 3. leaf_path（parallax 0.60，400m，opacity .80，fade 25，tileable=true）

- 参考：`previews/tiles/forest_leaf_path_tile.png`、`source/svg/forest_leaf_path_tile.svg`、check3、repeat3、seam probe。
- 主体：画面**下部**干叶土坡。地面体上缘是**整周期正弦**（1 或 2 周/tile，首尾 y 与斜率连续），体部 `#4A4030→#3A3226→#312A1F` 竖向渐变，上缘 alpha 柔和淡入；中央一条很弱土路弥散光（`#6A5B42` 低 alpha）；表面用固定种子在 3W 周期上稀疏散布干叶（暖褐 `#A89060` 约六成、落叶绿 `#6B8F71` 约三成）与少量细枝（`#5A4E38`）。
- 透明：地面上缘以上**全部真透明**；叶间露出透明而非铺满实片。
- 操作区留白：x≈.28–.71 纵带与旅人脚底 (0.34, .865) 附近刻意稀疏、低对比，禁止高对比杂斑干扰摇杆。
- 接缝：地面上缘在缝处 y/斜率连续（整周期函数保证）；叶斑跨 3W 发射，缝两侧密度/明度一致；土路光带若是周期元素必须 1 周/tile 完整闭合。
- 禁画：树干、树冠、光柱、亮盘、鸟、人物、脚印/道路标线、密到铺满的树叶、文字 UI。
- 正向提示：
  `安静二维插画，落叶林地面下半部，和缓起伏的干叶土坡，地面上缘为一整条连续周期曲线在左右边缘无缝衔接，暖褐到暗棕竖向渐变、上缘淡出到全透明，中央一条极淡土路，两侧稀疏干叶与细枝用均匀周期密度散布，中央纵向区域保持干净留白，低饱和，画面上半部纯透明，水平无缝 repeat-x tile 1080x1920，无接缝亮线，竖构图`
- 自检：三底地面上缘软过渡无硬切线；repeat3 + 四偏移视口地面无高差跳变、叶密度均匀、无周期网格。

## 4. 零新增付费 API 的实现路线（当前无新森林付费预算）

本设计本身零付费 API（Python PIL + 手写 SVG）。MiniMax 制作候选时同样允许、且优先走零 API 路线；**不得借用雨林 8 次授权**。任选其一或混合：

1. 结构复刻（推荐，最可控）：直接以 `source/svg/forest_{layer}_tile.svg` 为底稿，在 Inkscape/Figma/Krita 中做笔触质感细化（柔边、手绘团簇、叶形），保持图元坐标与 3W wrap 结构不变；导出 3240 宽母版后折叠回 1080 tile。
2. 脚本细化：在 `sw021_tile_model.py` 同结构上增加质感层（噪点极低透明度、手绘边缘扰动），仍在 3W 画布渲染并折叠；确定性种子保证跨缝一致。
3. 生图工具（若后续单独获批预算才可用）：必须使用 §1–3 的正向 + 通用负提示，并明确 `seamless horizontal tile, repeat-x, edges match exactly, 1080x1920, RGBA transparent background`；生成后**强制**走 3W 折叠重制接缝（生图模型的「seamless」通常只保证纹理不保证图元闭合），并重做全部三底/拼接/偏移目检。没有书面预算批准不得使用任何付费生图。
4. 手工绘制：Krita/Procreate 先画 3240×1920 横长卷，再裁切折叠；适用树干与冠线的手绘感。

## 5. 交付与验收（MiniMax 侧）

- 每个候选层交付：1080×1920 RGBA PNG 母版 + 编码后 webp（≤400KB）+ check3 三底 + repeat3 + 四偏移视口图 + 缝差数值 JSON（沿用 `sw021_preview_checks.json` 同字段口径）。
- 目录归 MiniMax 所有（`design/assets/forest/candidates/...`），Trae 不代写候选；候选 manifest 必须带 `design_ref`（SW-021、handoff 路径、spec 路径与 spec sha256，sha256 以批准后的 head 为准）。
- 在 Antigravity 批准 SW-021 设计之前开始的候选，`status` 只能是风险自担的预制作；设计变更会使旧候选失去引用，需重审。
- 六阶段合成检查：把三层候选按 design-spec `phase_mapping_frozen` 公式与复用的 light_shows/clearing 合成 0/100/265/425/630/785m，0m 必须仍近黑、785m 终景亮盘只来自 clearing。
- 素材不烘焙 UI/文字/人物；不解决触摸/无障碍，那是 ZCode + QA 范围。
