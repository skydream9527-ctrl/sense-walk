# SW-011 r1 · 森林五层素材制作提示词（交付 MiniMax）

本文件是可追溯的生产输入，不代替真实素材。MiniMax 据此制作候选，仍须按 `docs/collaboration/contracts/visual-assets.md` 独立验收（候选最多声明 `candidate`，批准来自 Antigravity）。

## 0. 所有层共用约束

- 设计依据：`design/05-visual-design/SW-011/r1/design-spec.json`（画布/锚点/色板/相位）。
- 统一风格参考：`previews/forest_style_reference.png`、`previews/composition_guide.png`、`previews/layer_map.png`。
- 画布：1080×1920，PNG 真实 RGBA 透明；坐标归一化 0–1。
- 光源：统一**右上斜射**（俯角 12–20°），所有层方向一致；共享地平线与脚底基线。
- 旅人锚点 x=.34、脚底 y=.865（程序绘制，**不要在任何素材里画人**）。
- 下方 45%（y=.55–1.00）是摇杆触控区：低对比、干净，**不烘焙**任何按钮/文字/图标/摇杆/米数/暂停标志。
- 透明：树间、天空、地面上缘、光与辉光之外一律真透明 alpha=0；**禁止**黑色/深色矩形底、白边、抠图光晕、投影硬边。
- 色板（契约六色为主）：void `#060806`、轮廓 `#1A2820`、树干 `#2D4A3E`、林光 `#8FA87A`、落叶 `#6B8F71`、暖褐 `#A89060`；派生暗部 `#244036/#243A30/#22332A`、空地微光 `#A8C5A0`、光束 `#DDE7C4`、土坡 `#4A4030→#312A1F`。不要引入新色相、不要高饱和。
- 风格：安静二维插画、干净剪影、低饱和、柔和林光、适量留白；**干叶通透的落叶林**，不是湿雾浓密雨林。
- 输出：每层一张独立 PNG，只画该层内容；**不把六阶段预览的层透明度烘焙进 RGB/alpha**（每层按其自身完整不透明度出图，运行时由 app 按米数衰减）。
- 拼接：本轮全部 `tileable=false`，不要求无缝平铺；但左右构图需留出右侧溢出，避免关键主体贴死右边（运行时按高度铺满、左对齐、右侧溢出宽度内做有限横向视差）。
- 通用负提示（每层都附加）：
  `棋盘格, 方格, 同心环, 重复几何纹理, 32px/8px 对角网纹, 马赛克, 噪点颗粒, 矩形底色, 硬边抠图, 白边, 描边外发光, 文字, 水印, logo, UI, 按钮, 图标, 人物, 旅人, 建筑, 道路指示牌, 高对比, 霓虹, 闪光, 雨, 浓雾, 雨林阔叶, 藤蔓, 苔藓湿面, 恐怖元素, HUD`

## 1. tree_outline（parallax 0.30，80m，目标 opacity .60，fade 20）

- 参考：`exports/forest_tree_outline.png`、`previews/layer_checks/forest_tree_outline_{black,white,magenta}.jpg`、`source/svg/forest_tree_outline.svg`。
- 主体：远处**两排**阔叶树冠线，柔圆团簇；后排更虚更冷（约 `#22332A`），前排略实（`#1A2820`）。冠线集中在 y≈.55–.85 的横向起伏带，团簇大小高低随机但节奏平缓。
- 透明：冠线以上的天空、团簇之间的空隙、画面下缘全部真透明；靠柔和的纵向衰减在 y≈.64–.83 之间融入透明。
- 禁画：竖树干、树枝细节、地面、土坡、光柱、鸟、人物、任何整片背景填充。
- 正向提示：
  `安静二维扁平插画，远处落叶林树冠剪影，两排柔圆重叠的阔叶团块，水平起伏林线，低饱和深墨绿 #1A2820/#22332A，干净矢量感边缘带轻微柔化，树间真透明，黑底上也自然，竖构图 1080x1920，留白通透，无地面无树干`
- 边缘/裁切：冠线横向铺满略超宽；上下与团簇间透明；不依赖底色。
- 自检：黑/白/洋红三底都只见冠线、无矩形底；无任何周期纹理。

## 2. tree_trunks（parallax 0.30，240m，目标 opacity .70，fade 25）

- 参考：`exports/forest_tree_trunks.png`、三层底检查图、`source/svg/forest_tree_trunks.svg`。
- 主体：约七根中景直立树干，微摆、底部带轻微根扩，粗细高低错落；树干做**竖向体积渐变**（两端 `#244036` 没入暗部、中上部受光到 `#2D4A3E`），最右侧一根为最暗前景纯剪影（`#243A30`）。右上来光给右侧一道很细的边光，少量极简枝桠。树后可有**极弱**的大柔斑林间空气光（`#8FA87A`，感观很淡，大半径柔化），仅作空气感。
- 透明：树间、树冠以上、地面以下真透明；树干顶部向上淡出黑幕、底部在触到地面前淡出（不要画地面）。
- 禁画：第二套树林、重复贴树皮照片纹理、地面/落叶、明显光柱、鸟、文字人物、矩形底。
- 正向提示：
  `安静二维插画，数根高耸细长的落叶林树干剪影，轻微弯曲与根部展开，竖向柔和明暗渐变体现体积，右上方向微妙边光，低饱和墨绿 #2D4A3E/#244036，最右一根更深的前景树，树与树之间真透明，背景纯透明无填充，竖构图，留白，极简，不要树皮照片纹理`
- 边缘/裁切：树干可超出顶部；横向铺满略超宽；林间光必须是柔斑不是竖条硬光柱。
- 自检：三底上树干边缘干净、无矩形底；竖斑为自然结构不是等距条纹/棋盘。

## 3. leaf_path（parallax 0.60，400m，目标 opacity .80，fade 25）

- 参考：`exports/forest_leaf_path.png`、三层底检查图、`source/svg/forest_leaf_path.svg`。
- 主体：画面**下部**干叶土坡。和缓起伏的地面体（`#4A4030` 到 `#312A1F` 竖向渐变，上缘透明淡入），中央一条很弱的土路光带，两侧低矮落叶堆柔斑；表面稀疏散落干叶（暖褐 `#A89060` 约六成、落叶绿 `#6B8F71` 约三成、少量枯枝褐），夹少量细枝。
- 透明：地面起伏上缘（y≲.71）以上**全部真透明**；叶片之间露出底色而非铺满地的实片。
- 留白要求：中央纵向触控带（x≈.28–.71）与旅人脚底（x=.34,y=.865）附近刻意稀疏、干净，避免高对比杂斑干扰摇杆。
- 禁画：树干、树冠、光柱、鸟、人物、清晰脚印/道路标线、密到铺满的树叶、文字 UI。
- 正向提示：
  `安静二维插画，落叶林地面的下半部，柔和起伏的干叶土坡，暖褐与暗绿的稀疏落叶、少量细枝和低矮叶堆，中央一条极淡土路，低饱和，地表上缘淡出到全透明，中央触控区域保持干净留白，竖构图 1080x1920，画面上半部纯透明`
- 拼接：`tileable=false`，不做无缝；右侧留溢出。
- 自检：三底上地面上缘为软过渡无硬切线；无重复叶纹网格。

## 4. light_shows（overlay，600m，目标 opacity .65，fade 30）— 重点修正层

- 参考：`exports/forest_light_shows.png`、`previews/layer_checks/forest_light_shows_{black,white,magenta}.jpg`、`source/svg/forest_light_shows.svg`。
- 历史教训：v4/v5 拒绝稿在此层出现 **32px 对角棋盘/网纹**与矩形硬边光柱。本层**必须**是干净的柔和体积光。
- 主体：**三束**自右上向左下斜射的体积光 + **三只**远处小鸟。光束是纵向拉长的**椭圆/纺锤形柔辉光**（`#DDE7C4` 低不透明度），光源在画面外右上方，屏内只保留柔和中段，中心最亮、向四周和末端**平滑衰减到全透明**，边缘无任何直线/几何边界。远鸟为简洁 V 形弧线小剪影（`#8FA87A`），集中在 x≈.60–.68、y≈.14–.19，很小很克制。
- 透明：除三束渐隐光与三只鸟外全部真透明。
- 禁画（本层强化）：矩形/梯形/多边形光柱硬边、光束轮廓线、第二套树林或背景、天空渐变填充、十字星芒、镜头眩光、光斑阵列、**任何棋盘/方格/同心环/重复网纹**、文字人物。
- 正向提示：
  `极简安静的森林光束，三束从右上方画面外斜射下来的柔和体积光，长椭圆朦胧光带，边缘完全柔化融入黑色，淡暖白绿色 #DDE7C4 很低不透明度，三只极简远鸟小剪影，背景纯透明无任何填充，无硬边无几何形状，竖构图 1080x1920，干净，空气感`
- 边缘/裁切：光束在黑底上也必须看不到矩形边界；鸟与光分离清晰。
- 自检（必须过）：黑/白/洋红三底目检无任何方格/环纹/矩形底；放大光束中心与边缘无周期纹理；alpha 掩码平滑。**目检不可用统计阈值替代。**

## 5. clearing（overlay，760m，目标 opacity .90，fade 25）— 重点修正层

- 参考：`exports/forest_clearing.png`、三层底检查图、`source/svg/forest_clearing.svg`。
- 历史教训：旧稿 785m 合成中心出现 **32px 对角能量 21.8%** 的重复纹理，判定为问题层。本层只允许**单一**平滑辉光。
- 主体：一块安静的林间空地微光——一个椭圆径向辉光（`#A8C5A0`，中心最亮向外平滑衰减，中心约 x=.66/y=.40），下方可叠一条很弱的远处开口横辉。仅此而已。
- 透明：辉光以外全透明；中心到边缘连续平滑到 alpha=0。
- 禁画（本层强化）：同心圆环、光圈、放射光线阵列、第二套树林、地面纹理、棋盘/方格/对角网纹、矩形底、亮斑重复、文字人物。
- 正向提示：
  `极简单一柔和径向辉光，林间空地上方安静的一团淡绿光，#A8C5A0，椭圆，中心柔和最亮、边缘无缝淡出到全透明，无环无光线无纹理，背景纯透明，竖构图 1080x1920，大面积留白，宁静`
- 自检（必须过）：三底目检只有一团平滑光、无环无纹；alpha 掩码是单一连续梯度；叠加到 785m 终景中心放大无任何周期性网纹。

## 6. 交付与验收提醒（MiniMax）

- 候选目录：`design/assets/forest/candidates/<task-id>/r<revision>/`，含 `png/ webp/ checks/{black,white,magenta}/ checks/stages/ manifest.json`。
- 每层 ≤400KB、五层合计 ≤2MB（webp 入包预算）；宽目标 1080，记录真实原始尺寸，不得放大旧 768×1376 冒称原生 1080。
- manifest 每层记录 layer_id/file/sha256/width/height/bytes/alpha_channel/render_role/tileable/origin/process/quality_status/checks/limitations；`origin` 写明生成服务与条款，**不得标 CC0**；API 账本如实记成功/失败/费用，未知写 unknown。
- 需提供 0/100/265/425/630/785m 六阶段按真实 smoothstep 透明度的合成检查图（void 与旅人按程序绘制，不要把人画进素材）。
- 0m 必须纯黑幕（除程序旅人外无风景提前揭示）。
- `tileable=false`：不要提供或宣称无缝平铺；当前渲染仅有限横向滑动。
- 批准前候选状态只能是 `candidate`；设计批准与素材批准是两道独立审核。
