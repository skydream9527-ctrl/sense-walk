# 森林 · forest

| 字段 | 值 |
| --- | --- |
| ID | `forest` |
| 要求距离 | **400 m** |
| 建议时长 | ~14 min |
| `stickCurveId` | `comfort_v1` |
| MVP | 主场景（Week 1 已有 JSON） |

---

## 1. 情绪 / 减压意图

- **Mood**：树荫、清爽、生命感。
- **减压意图**：干爽落叶与远鸟营造「被自然轻轻接住」；比雨林更透气、更明亮（仍从黑幕长出）。
- **文案气质**：「落叶很轻。走着走着，林光会来。」

---

## 2. 色板

| 用途 | 色值 |
| --- | --- |
| 黑幕 | `#060806` |
| 轮廓树木 | `#1a2820` 剪影 |
| 树干/林间光 | `#2d4a3e` + `#8fa87a` 光斑 |
| 落叶路径细节 | `#6b8f71` / 暖褐点缀 `#a89060` |
| 选景卡片 | 极弱 `#2d4a3e` |

与雨林区分：少雾、多干叶暖色，林光更「透」。

---

## 3. 声景身份

| 层 | 内容 |
| --- | --- |
| 脚步 | 落叶土路，干爽碎裂感 |
| 环境 | 虫鸣、远鸟（克制密度） |
| 振动 | `footstep_soft` · ~650ms，规律偏柔 |
| 禁止 | 与雨林共用同一湿脚步素材 |

资源：`audio/forest_*.ogg`（既有命名约定）。

## 6. 摇杆关系

- 落叶坡：甜点略收，拉满更「踩不稳」的步态抖动（轻微、不闪屏）。
- 土坎前：文案「抬脚，不用跑。」
- 跳跃宽窗；自动优先。

---

## 7. 失败处理

同通用地形：不扣命、温和重试、重试不计距。无 Game Over。
