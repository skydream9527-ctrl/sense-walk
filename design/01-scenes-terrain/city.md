# 城市 · city

| 字段 | 值 |
| --- | --- |
| ID | `city` |
| 要求距离 | **1000 m** |
| 建议时长 | ~16 min |
| `stickCurveId` | `comfort_v1` |
| MVP | 主场景（新配置） |

---

## 1. 情绪 / 减压意图

- **Mood**：夜色人行道、疏离、水泥与远灯。
- **减压意图**：把「城市压力场」改写成可步行的安全夜路——远车流被低通，只留疏离的安静。
- **文案气质**：「灯在很远的地方。这条人行道只属于你的脚步。」

## 3. 声景身份

| 层 | 内容 |
| --- | --- |
| 脚步 | 鞋底磕砖石 / 柏油，短促清晰 |
| 环境 | 远车流**低通**、空调外机、偶发远处喇叭极轻 |
| 振动 | `curb_tap`：短、干净，对齐步伐 |
| 硬限制 | 城市层音频务必克制；严格响度上限；勿嘈杂混音 |

资源：`audio/city_steps.ogg`、`audio/city_night_bed.ogg`。

## 4. 视觉层时间轴

| atMeters | 听/触 | 视觉 |
| --- | --- | --- |
| 0 | silence | void |
| 100 (~10%) | footsteps | 远景轮廓 |
| 300 (~30%) | ambience | 街灯 / 建筑剪影 |
| 500 (~50%) | haptics | 更近的街道元素 |
| 750 (~75%) | deep_bell 远钟声微露 | 远景天际微明 |
| 950 (~95%) | 环境音微敛 | 街角长椅灯晕 |
| 1000 | 通关 | 保持完整 |

## 6. 摇杆关系

- 路缘跳跃：宽窗；轻点或自动；**非**节奏游戏踩点。
- 缓坡道：甜点标准；拉满显得「鞋底发硬」。
- 城市景更需避免竞技感 UI。

---

## 7. 失败处理

绊缘石：短暂停 + 重试；不计距。无 NPC 冲突、无交通事故事件。
