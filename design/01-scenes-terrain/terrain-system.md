# 通用地形系统

> 约束源：DEVELOPMENT.md §5、§4。地形服务于正念慢走，**不做高压平台跳跃考验**。

---

## 1. 目标

1. 路径有高程 / 障碍，视觉与场景身份一致。  
2. 角色动作跟随地形：平地走、上坡攀、过坎跳、不平微调。  
3. 仅**有效前进**计入距离；防刷。  
4. 减压：宽松时间窗、不扣命、温和重试。

---

## 2. 路径模型

- 参数化弧长 \(s \in [0, L]\)，\(L\) 与 `requiredDistanceMeters` 对齐（或门禁取有效前进累计）。  
- `pathProfile.segments[]`：`{ from, to, kind, grade?, hint? }`  
- 景色层增强后，坡/坎可读性提高；早期黑幕阶段路径暗示极弱——**仍按 atMeters，不可提前看清整条捷径**。

### kind 枚举

| kind | 含义 | 角色动画 | 速度修正 |
| --- | --- | --- | --- |
| `flat` | 平坦 | walk | 无 |
| `slope_up` | 上坡 | climb / 俯身 | 按 grade 略降（乘子 ~0.85–0.95） |
| `slope_down` | 下坡 | walk 稳健 | 可略稳，不加速超硬顶 |
| `gap_hop` | 可跨越间隙 | jump / 轻抬脚 | 通过前可自动减速 |
| `uneven` | 不平地面 | walk 微调 | 极轻抖动，不惊吓 |

---

## 3. 坡（slope）

| 规则 | 说明 |
| --- | --- |
| grade | 建议 0.05–0.10；沙漠可到 ~0.10；城市更缓 |
| 摇杆 | 甜点仍存在；峰值可略降；拉满更钝 |
| 失败 | 无「掉下山崖」；松手即缓停 |
| 实走 | 屏幕起伏仅氛围，**不要求户外做攀爬操作** |

---

## 4. 跳跃（gap_hop）

| 规则 | 说明 |
| --- | --- |
| 触发 | 首版：**自动**或**宽窗轻点**（开放决策 #10） |
| 时间窗 | 宽松（秒级，非帧级 QTE） |
| 成功 | 播放轻跳动画，\(s\) 越过间隙后继续计前进 |
| 失败 | 短暂停步 / 小幅后退动画；温和重试；**无弹窗轰炸** |
| 命数 | **无** |
| 刷距 | 重试过程中的来回位移 **不计入** |

---

## 5. 不平地面（uneven）

- 步态 IK/动画微调即可。  
- 可配合极轻 haptic，但不得密集到焦虑。  
- 不计「平衡失败」。

---

## 6. 有效距离会计（防刷）

**有效进度** = 沿路径向前的有效位移（米）。

| 计入 | 不计入 |
| --- | --- |
| 沿路径前进的位移 | 原地踏步、反复卡同一坎刷动画 |
| 成功通过坡/跳后的前进段 | 坠落 / 滑回 / 重试过程中的来回位移 |
| 虚走与实走同一套「有效米」语义 | 倒走、偏离路径的无效移动 |

实现建议：

- 进度 = 单调前向包络（只增不减，或仅极小回退窗口后钳制）  
- 卡关重试：\(s\) 不增加则距离不涨  
- 倒推 / 摇出路径：不计有效距离  

---

## 7. 与舒适摇杆的耦合

```
v_cmd = ComfortStickMapper(d)          # 非单调甜点曲线，硬顶 1.4 m/s
v_terrain = TerrainSpeedFactor(kind, grade)
v = min(1.4, v_cmd * v_terrain)
```

- 地形不能成为「技巧速通」通道。  
- 即使甜点 + 全平地，清关时间下界仍由 `requiredDistanceMeters / v_peak` 决定。

## 8. 反压力 / 减压约束（验收用）

| ID | 约束 | 验收 |
| --- | --- | --- |
| T1 | 无命数、无 Game Over | 失败仅重试 |
| T2 | 跳跃窗宽松 | 非熟练用户可过 |
| T3 | 失败无恐吓 UI | 无红闪、无巨响 |
| T4 | 重试不计刷距 | 日志/单测：重试期间 meters 不涨 |
| T5 | 文案减压 | 「慢一点、看清路」类，无「加油冲击」 |
| T6 | 实走不要求跳跃操作 | 实走无 gap 操作提示 |

## 9. 分场景地形气质（汇总）

| 场景 | 元素例 | 典型动作 |
| --- | --- | --- |
| 雨林 | 湿根、缓坡、浅沟 | 小心抬脚、攀湿坡、轻跃小沟 |
| 森林 | 土坎、落叶坡 | 上坡、越矮坎 |
| 沙漠 | 沙丘起伏、软沙 | 费力上坡、下坡略稳 |
| 城市 | 路缘、缓坡道、砖缝 | 上台阶感轻跳、坡道走 |
| 夜径 | 石板落差 | 慢步、小幅抬脚 |

各景绝对段表见对应场景 md。

## 10. 与景色层层展开

| 阶段 | 地形可读性 |
| --- | --- |
| 黑幕早期 | 路径暗示极弱（轮廓线/极淡） |
| 氛围层后 | 近处地面材质隐约可见 |
| 主体景后 | 坡度/坎更清晰 |
| 细节层后 | 完整可读，仍不提供「小地图捷径」 |
