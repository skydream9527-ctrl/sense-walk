# 旅人 · 默认角色完整规格

**代号**：Traveler / 旅人  
**用途**：全场景默认可控角色（虚走）；实走可降级为剪影。

---

## 1. 外形

### 剪影与比例

- 头身比约 **1:3.2–1:3.5**（略简化成人形，非儿童、非巨人）  
- 清晰外轮廓：微圆的头部、单件外套/斗篷下摆、简洁双腿  
- 正面/侧面以 **3/4 侧视沿路径** 为主（侧向行走可读性最好）  
- 无五官细绘；可用一点鼻影或帽檐暗示朝向  

### 中性默认服装

| 部件 | 描述 |
| --- | --- |
| 上装 | 中长外套或薄斗篷，下摆随走轻微摆动 |
| 下装 | 宽松裤，剪影干净 |
| 鞋 | 简单旅行靴轮廓 |
| 色 | 默认中灰绿 `#6a7a6e` + 暗部 `#2a322c`；边缘 1px 弱光 `#c4d4a8` @ 20% |

### 场景轻度着色（可选，同一骨架）

| 场景 | 着色提示 |
| --- | --- |
| 雨林 | 外套偏湿绿，边缘雾青 |
| 森林 | 默认即可，略暖 |
| 沙漠 | 沙色披巾变体（见变体 A） |
| 城市 | 外套偏冷灰蓝 |
| 夜径 | 极弱暖点（灯笼变体 B） |

**不做**换装商城、稀有度、付费皮肤压力。

## 2. 动画状态机

```
                    ┌──────────┐
          ┌────────►│  idle    │◄────────┐
          │         └────┬─────┘         │
          │ 松手/停步     │ 前进输入        │ 落地稳定
          │              ▼               │
          │         ┌──────────┐         │
          │         │  walk    │─────────┤
          │         └────┬─────┘         │
          │    入坡段     │    入 gap     │
          │              ▼               │
          │         ┌──────────┐    ┌────┴─────┐
          │         │  climb   │    │  jump    │
          │         └────┬─────┘    └────┬─────┘
          │              │               │
          │              └───────┬───────┘
          │                      ▼
          │               ┌──────────┐
          └───────────────│  rest    │  （可选：长时间静止的呼吸）
                          └──────────┘
```

| 状态 | 触发 | 表现 | 备注 |
| --- | --- | --- | --- |
| `idle` | \(d=0\) / 实走无步 | 轻呼吸起伏 | 黑幕中仅弱轮廓 |
| `walk` | 平地/不平有效前进 | 循环步态；速度贴 \(v\) | 甜点区步态最自然 |
| `climb` | `slope_up` 段 | 俯身、步频略慢 | 与地形降速同步 |
| `jump` | `gap_hop` 成功窗 | 轻跃短动画 | 失败→短顿→idle/walk |
| `rest` | 静止 > N 秒（可选） | 更慢呼吸 | 不强制；勿打坐说教 |

### 紧张区 / 拉满（虚走）

- 进入紧张区（\(d\) 高）：步态略僵、肩线紧——**轻微**，不闪屏。  
- 拉满：同一 walk/climb 但「吃力」变体（步幅小、频率别扭），呼应速度变慢。

## 3. 暗场 → 亮场可读性

| 景色阶段 | 角色绘制 |
| --- | --- |
| void 黑幕 | 低饱和轮廓 + 极弱边缘光；不发光刺眼 |
| 氛围层 | 轮廓对比略增；仍低于景色抢戏 |
| 主体/细节 | 正常材质；角色始终小于主体景面积 |

角色**不**随通关播放烟花或变身。

---

## 4. 支持平静的设计要点（验收）

- [ ] 无面部夸张表情包  
- [ ] 无连击、无伤害数字、无血条  
- [ ] 跳跃失败无摔跤喜剧动画（避免嬉闹破氛围）  
- [ ] 通关姿态：停下、轻缓呼吸或微微抬头看景——**不鼓掌、不蹦跳**  
- [ ] UI 不在角色头上挂名字/等级  

---

## 5. 变体简述（非完整规格）

### 变体 A · 沙色披巾（沙漠偏向）

- 同骨架；斗篷改为沙色披巾 `#c4a882`  
- 动画状态机不变  
- 可作沙漠默认着色，而非独立角色

### 变体 B · 微光灯笼（夜径偏向）

- 一手持极小灯笼光点（半径小、亮度低）  
- 仅辅助夜径可读，不作照明玩法  
- 其他场景可关

## 6. 技术提示（文档层）
