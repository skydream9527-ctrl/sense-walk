# 角色总览

## 默认方案

MVP **一个默认角色「旅人」**，中性剪影，可轻度随场景换色/配件，但不强制多角色养成。

| 项 | 决策 |
| --- | --- |
| 数量 | 1 完整规格 + 1–2 短变体 |
| 风格 | 2D 低成本剪影 / 软边缘插画，非写实、非 Q 版夸张 |
| 辨识 | 远距离可读的头身比与斗篷/外套轮廓 |
| 社交 | 无其他玩家形象、无排行形象 |

## 为什么这样设计支持平静

1. **少脸部细节** — 避免表情夸张抢戏  
2. **动作幅度小** — 走/攀/跳柔和，无胜利跳舞打扰通关余韵  
3. **暗场可读** — 黑幕阶段仅靠浅色描边/弱光轮廓存在，不刺眼  
4. **不挡景** — 角色偏画面下部或路径线上，景色层在后方展开  
5. **无战斗装备** — 去掉「闯关角色」心理暗示  

## 与模式关系

| 模式 | 角色表现 |
| --- | --- |
| 虚走 | 完整：随摇杆与地形切换动画 |
| 实走 | 可更克制：小号剪影或仅路径点；规则仍黑幕→层层展开 |
