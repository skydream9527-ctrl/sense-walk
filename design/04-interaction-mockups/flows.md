# 关键路径

## 主路径：选景 → 选模式 → 会话 → 通关

```
[冷启动]
    │
    ▼
[Home 场景选择] ──选择卡片──► [Mode 模式选择]
    │                              │
    │                              ├─ 虚走 ──► 请求振动等（通常已有）
    │                              └─ 实走 ──► ACTIVITY_RECOGNITION
    │                                          （可选 GPS 辅助）
    │                              │
    │                              ▼
    │                         [Session 开始]
    │                              │
    │                    黑幕 + 极简 HUD
    │                              │
    │              ┌────────虚走：摇杆+地形──────┐
    │              │                            │
    │              │     按 atMeters 解锁        │
    │              │                            │
    │              ▼                            ▼
    │         [满距]                         [长按放弃]
    │              │                            │
    │              ▼                            ▼
    │         [通关页]                       [放弃页]
    │              │                            │
    └──────────────┴──────────回 Home───────────┘
```

## 点击预算

冷启动 → 开步 ≤ **4** 次有效点击（含选模式）。

示例：点场景(1) → 点虚走(2) → 点开始(3)。若场景默认选中上次，可更少。

## 分支

| 分支 | 行为 |
| --- | --- |
| 会话中系统返回 | 进入放弃确认，非静默退出 |
| 权限拒绝（实走） | 说明用途；可改选虚走 |
| 无计步器 | 引导虚走 |
| 车载检测（实走） | 暂停累计；温和提示 |
| 首次虚走 | 轻提示拉满≠最快 |

## 非路径（不做）

- 会话内商店、跳过、加速条  
- 通关强制分享  
- 连胜火焰与羞耻贴纸
